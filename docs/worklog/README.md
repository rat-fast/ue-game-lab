# 工作记录

这里按时间记录本仓库有长期回溯价值的重要工作、讨论和判断，不保存完整聊天记录，也不代替各项目的当前架构与模块文档。

## 记录方式

- 每个自然月使用一个 `YYYY-MM.md` 文件。
- 每条记录只说明重要内容及其影响。
- 实际完成的能力、讨论形成的判断和已经验证的结果必须明确区分。
- 同一天、同一主题的内容合并记录，不写逐文件修改和普通操作流水。
