# AI Workflow

这里放 AI 协作相关资产。

适合放：

- Agent 工作流说明
- 上下文模板
- 任务模板
- Review 模板
- 项目记忆
- AI 可读取的规则文件

按需加载的专项能力放在仓库 `.codex/skills/` 下；Skill 使用的共享上下文、登记表和其他 AI 产物放在本目录对应的子目录中。例如 UE MCP 使用 `.codex/skills/ue-mcp/SKILL.md`，其端口登记表位于 `ai/ue-mcp/ue-mcp-ports.json`。

这个目录不放大模型输出的所有临时草稿，只放可以复用、可以维护的 AI 工作流资产。
