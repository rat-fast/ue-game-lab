# 03：空间数据读取

## 任务目标与输入

由独立读取 Agent 消费 [02 导出的画面和数据](02-SpatialDataExportTools.md)，理解本次任务涉及的模型、动作与对象空间关系，留下后续配置 AI 可直接使用的说明。遵循[批次共用边界](README.md)。

## 初步工作范围

本任务负责工具的使用方法与判断流程：根据适配目标确定观察哪个场景中的角色和技能释放、哪些时段/部位和视角，安排 inspect/capture 调用，判断是否需要补充材料。Montage 等绑定从实际释放取得，不另行替换成孤立动作预览。这些策略不放进 02 工具内部，具体规则后续细化。

先从导出返回的 manifest.json 读取状态与索引，再读取实际配置、事件、空间样本和对应画面；partial/failed 的缺失范围必须保留。工具事实的 JSON/JSONL 与 PNG 是输入，读取后的空间说明仍是独立结构化文字产物。

- 确认材料对象、版本、Montage 播放条件、时段和参照条件；先查找适用的已有说明，足够则复用，不足才请求补充导出。
- 理解相关部位在目标时刻及必要前后过程中的位置与运动，说明骨骼/挂点参照和实际模型外形的关系。
- 理解被放置对象的可见主体与原点、方向、尺寸的关系；发现画面、查询信息或时间对应不一致时标出问题。
- 保存结构化文字说明，关联源数据和画面，区分工具事实、视觉解释、候选建议和不确定性；明确适用范围及缺少的证据。

## 初步交付与验证

交付可发现、可复用的空间说明及未解决项。后续配置 Agent 应能据此理解相关空间关系，按需回查依据，而不必反复从头读图。本任务不写入实际运行配置，也不预先决定每个任务的最终偏移。

## 下一轮细化

确定读取时必须回答的问题、文字组织方式、补充材料条件和交接完整性；具体读取入口与执行方法待讨论。
