# 04：空间适配配置

## 任务目标与输入

配置 Agent 接收具体适配意图，消费 [03 的空间说明](03-SpatialDataReading.md)，通过 [01 的配置能力](01-SkillSpatialConfigurationSupport.md)完成实际适配，并使用 [02 的观察工具](02-SpatialDataExportTools.md)检查结果。遵循[批次共用边界](README.md)。

## 初步工作范围

配置后的复查策略属于本工作流：决定场景、角色和技能、关注的事件过程及视角，以及何时调整或补采；02 负责脚本驱动真实释放并返回采集材料，不把独立 Montage 预览当作实际配置生效证据。

- 核对模型、动作、对象、配置与资料的适用条件；资料不足时请求补充，不沿用失效结论。
- 自主选择适合任务的参照、相对位置、朝向、大小及生成/跟随关系，用户无需逐个指定骨骼名或坐标。
- 应用实际配置并确认生效，观察目标时刻及必要前后过程；发现穿插、悬空、朝向或比例等可修正问题后调整、再次观察。
- 按适用行为检查角色位置/朝向变化、生成后独立运行、持续附着；真实投射物另查相关轨迹、遮挡和近墙情境。

## 初步交付与验证

交付实际配置、资料引用、调整依据、运行画面和结论。配置合法或保存成功不能替代视觉检查；不能取得画面或解决冲突时，明确未完成范围。正常适配自主完成，涉及未定玩法取舍的问题再交负责人决定。

## 下一轮细化

确定具体样本的适配意图、允许调整内容、检查条件与完成判断；配置入口缺口返回 01，工具缺口返回 02，空间说明缺口返回 03。本任务不承担前置能力建设，也不扩展为技能功能全面回归。
