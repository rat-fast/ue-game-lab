# 02：空间数据与观察工具

## 任务目标

依据[批次共用边界](README.md)，围绕 [01 的配置内容](01-SkillSpatialConfigurationSupport.md)，提供 AI 理解和检查空间关系所需的查询、画面及导出工具。工具负责可靠取得材料，不替读取 Agent 解释空间关系，也不替配置 Agent 决定最终参数。

## 初步功能范围

- 定位指定模型、动作、对象及时刻/区间，说明观察内容与实际播放内容的对应条件；支持概览后选择相关部位继续查询。
- 查询相关部位/对象的位置、朝向和参照空间；按需提供被放置对象的原点、方向、尺寸及预览，明确缺失、近似和限制。
- 将查询点或候选放置点显示在模型/场景中，支持按需补视角、部位和时段。单张截图不替代准确三维查询。
- 导出画面与结构化文本，保留来源、对象身份、时刻、参照及适用条件；返回产物位置，支持后续发现、复用和识别条件变化。
- 支持 04 配置后的实际运行画面获取及再次观察；动作预览与实际运行结果应可辨认，不能用前者代替后者。

## 初步交付与验证

交付可调用工具、操作说明、输出样例及限制。用一个样本检查定位、查询、可视对照、补充导出和材料回查；已有工具可复用，缺口再补齐。本任务不建设游戏运行配置功能。

## 下一轮细化

根据具体配置判断逐项确定输入、必须导出的材料、播放时刻映射、运行观察条件和失败反馈；不预设全量采集或要求全部对象属性都能自动准确读出。
