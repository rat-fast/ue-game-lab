# 04：公共验收

## 目的

验证公共表现生产能力和运行链满足本批需求。文档建立或代码存在不等于验收通过；每项需记录版本、入口、输入、输出/回读、运行结果和未覆盖项。

## 验收矩阵

| 编号 | 范围 | 通过条件 |
| --- | --- | --- |
| A01 | 动画基础数据 | Event Graph 中核心计算/判断有可追溯的迁移目标，修改后的职责和输入可定位，基本状态在运行中可观察。 |
| A02 | 状态迁移 | Idle、Move、Jump、Fall、Land 可复现；逐项与迁移前对照，差异有说明，未完成项明确列出。 |
| A03 | 结构化内容 | 能定位、读取并局部修改动画内容，回读结果与实际生效内容一致，差异可 Review。 |
| A04 | 内容校验 | 缺失、无效或不兼容的动画引用能指出具体条目和原因；正常内容通过校验。 |
| A05 | Montage | Slot、Section、Notify、Blend、Play Rate、片段和 Skeleton 信息能够机器读取、修改、回读和校验，错误定位到具体内容。 |
| A06 | 火球纵向链 | 真实技能事件、动作开始、释放/效果及终态可串联观察；资源和 Montage 数据可从生产入口回读，并在 UE 运行中复验。 |
| A07 | 三项迁移 | 区域爆发、修复、燃烧效果都按各自真实运行事实完成关联验证，且行为差异未被统一处理抹平。 |
| A08 | 取消与恢复 | 取消/完成只作用于对应施法，重复或迟到事件无误清理；基础姿势恢复可见，独立持续效果不受动作清理误伤。 |
| A09 | 缺失资源 | 无资源或不可用资源时运行结果不变，玩家反馈不伪造施法、命中或效果，并能定位内容问题。 |
| A10 | AI 适配目标 | 人和机器能读取同一领域语义、对局部内容作可检查修改、回读生效结果并运行校验；差异可 Review、问题可定位。 |

## 证据要求

- 基础状态：默认角色、地图/运行入口、输入条件、各状态变化记录和对比结果。
- 内容生产：读取结果、修改内容、回读差异、校验报告，以及 UE 重新加载后的生效检查。
- 技能链路：至少记录 SkillId/Cast 身份、阶段/事件、动作状态、释放/效果结果、取消或完成和姿势恢复；持续效果需单独记录其生命周期。
- 未执行的验证标为待运行。静态路径、资产存在、自动化逻辑单测不能单独证明视觉通过。

## 明确排除项

本批验收不要求改变 UE 骨骼融合、姿势求值或动画压缩，不要求 Agent 自动编排或全自动创作，也不以单一火球样本替代另外三项技能迁移。
