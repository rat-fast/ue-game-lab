# 技能配置设计入口

## 定位

本目录描述具体技能内容：玩家如何操作、目标如何选择、何时生效、数值与效果如何组合、表现需要表达什么，以及怎样验收。技能侧实现可以只读取本目录、项目事实和程序线公开的能力接口。

本层不规定 GAS 类、C++ 文件、Blueprint 图表、最终配置字段、数据载体或 DSL。程序提供的能力接口是本层的实现依赖；如果能力无法表达技能语义，记录能力缺口并回到程序线评估。

## 内容约定

每个技能至少说明：

- 输入方式、目标关系与目标类型；
- 预览、确认、前摇、释放、引导/周期、收招和结束；
- 成本、冷却、范围、速度、持续时间等可调参数的业务意义；
- 实际命中、伤害/治疗/护盾/状态结果、叠加与移除；
- 移动、受击、死亡、目标失效、取消和 Reset 的行为；
- 反馈、失败原因、清理要求和可重复验收操作。

## 与公共能力的关系

技能只声明需要的公共能力和可观察语义，不复制公共规则正文。当前批次共用以下最小约定：开始前拒绝不产生正式副作用；成功开始后成本/冷却按技能声明时点提交一次；预览、施法、对象、效果和状态可有不同生命周期；完成不等于命中；实际结果记录真实数值；持续区间默认包含开始、不包含结束；死亡、目标失效和 Reset 按技能声明清理；同一技能请求可由 Player、AI、Test 以相同业务规则调用。

这些是技能消费公共能力时的语义摘要，程序接口、版本和支持范围以 `Docs/ProgramWorkflow/SkillSystem/` 现行文档为准。

## 阅读与交接

- [六技能索引](SkillDesigns.md)：进入各个独立技能正文。
- [核心策划入口](../RepresentativeSkillVerticalSlice.md)：批次范围与能力覆盖。
- 做技能实现时，先核对程序线能力目录和项目当前事实，再按本层技能设计提交能力缺口；不要求先阅读 Infrastructure 目录。
- 基建层改动只有在公共能力或接口语义变化影响本技能时才需要回看，并在交接中注明受影响的技能。

本层所有数值、交互细节和默认规则均为建议稿，待用户 review 与实际试玩确认。
