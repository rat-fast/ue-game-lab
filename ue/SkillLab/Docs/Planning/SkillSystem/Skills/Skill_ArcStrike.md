# Skill_ArcStrike 扇斩

## 文档定位与状态

本文是 SkillLab 当前批次的独立技能设计稿，负责本技能的操作意图、目标、阶段、参数、效果、表现和验收。

- 具体公共能力由 `Infrastructure/` 及当前批次基建需求提供。
- 程序实现读取本技能文档、项目事实和程序线公开接口；本文件不规定 GAS 类、C++ 文件、Blueprint 或最终配置载体。
- 下文数值与交互均为建议默认值，待用户 review、程序核对和实际试玩验证。


**体验与操作**：按槽位键预览鼠标方向扇形，左键捕获方向。角色停止移动并转向，经短前摇挥斩，范围内敌人各受一次伤害。

| 参数 | 建议值 |
|---|---|
| 输入/执行/关系 | Direction / LineCone 扇形 / Enemy |
| 成本/冷却 | SkillEnergy 15 / 3 秒 |
| 前摇/收招 | 0.25 / 0.15 秒 |
| 长度/全角 | 450 厘米 / 90 度 |
| 伤害 | 每目标 25 |
| 空间快照 | 原点取释放时施法者位置，方向取确认值 |

**命中规则**：按目标中心水平距离与角度判断范围，使用项目统一的空间容差；释放时检查存活、敌方、可选中与视线。按 Cast/本段/UnitId 去重，各目标记录独立效果结果。空范围正常释放、扣费并完成，记录 0 命中。

**终止与表现**：前摇移动/取消为 Cancelled，控制阻塞或死亡为 Interrupted；普通受伤继续。收招取消停止占用，保留已命中结果。预览与正式范围一致，挥斩一次、每目标命中一次；Reset 停止阶段/持续反馈。

| 验收操作 | 预期 |
|---|---|
| 两个生命 200 的敌人位于距离 300、偏角 ±20 度 | 各生命 175，能量 85，同 Cast、各自效果 |
| 距离 500、偏角 60 度、友方或隔墙 | 过滤，无效果 |
| 中心处于 450 厘米/45 度边界 | 按统一容差入选，预览一致 |
| 多碰撞组件、确认后移动鼠标、目标前摇中移动 | 本段每单位一次；方向快照；按释放时位置查询 |
| 空范围、前摇取消/死亡、收招取消、Reset | 空范围正常完成；前摇无伤害；收招保留结果；无残留 |

**能力需求**：前摇/收招阶段、扇形与视线查询、每单位去重、多目标实际结果、挥斩与预览反馈。
