# Skill_BurnField 烬地

## 文档定位与状态

本文是 SkillLab 当前批次的独立技能设计稿，负责本技能的操作意图、目标、阶段、参数、效果、表现和验收。

- 具体公共能力由 `Infrastructure/` 及当前批次基建需求提供。
- 程序实现读取本技能文档、项目事实和程序线公开接口；本文件不规定 GAS 类、C++ 文件、Blueprint 或最终配置载体。
- 下文数值与交互均为建议默认值，待用户 review、程序核对和实际试玩验证。


**体验与操作**：按槽位键显示圆形地面预览，左键确认位置，经前摇生成区域。敌人站内周期受伤并减速；生成后施法者可行动和施放其他技能。

| 参数 | 建议值 |
|---|---|
| 输入/执行/关系 | Ground / PersistentArea / Enemy |
| 成本/冷却/前摇 | SkillEnergy 20 / 5 秒 / 0.2 秒 |
| 距离/半径 | 1000 / 250 厘米 |
| 地面合法性 | 可行走地面；提交与生成重检距离及到中心的视线，超距拒绝 |
| 时长/周期/伤害 | 4 秒 / 1 秒 / 每目标每轮 10 |
| 减速/离开尾效 | 20% / 0.5 秒 |

**时序与命中**：位置确认快照。创建区间为 [创建时刻, 创建+4 秒)，伤害在相对 0、1、2、3 秒，共四轮。每轮查询当前合法敌方、按单位身份去重；进入不额外伤害，等待下一轮。进入立即获得区域减速贡献；成员变化按运行时更新，离开后贡献转为 0.5 秒尾效，再进入恢复维持。

**归属与清理**：区域创建后 Cast Completed，独立对象身份保留来源；区域外可通过对象/来源清理入口主动移除。多个区域分别结算伤害，减速按最强贡献聚合。区域到期、主动移除、施法者死亡或场景 Reset 均停止周期并清除此区域的减速贡献和尾效；目标死亡/关系非法同样清除对应贡献。原 Cast 保持已完成结果。前摇取消/死亡按公共终止；创建失败记录 Failed 并终止已开始 Cast，保留成本。

**表现需求**：合法地面预览、区域创建/销毁、每轮伤害、减速标记与尾效；循环区域绑定 ObjectId，状态绑定效果来源，清理分别跟随真实对象与状态。

| 验收操作 | 预期 |
|---|---|
| 生命 200、速度 600 敌人全程站内 | 四轮后生命 160，站内速度 480，到期恢复 600 |
| 第 0 轮后进入、第 2 轮前离开 | 仅第 1 轮伤害 10；离开 0.5 秒后恢复 |
| 多组件、两个区域重叠 | 每区域每轮一次伤害；两区各 10，减速仍 20% |
| 生成后施法者移动/施放其他技能 | 区域独立继续，来源可查 |
| 主动移除/死亡/Reset 恰在周期时刻 | 终止优先，未结算周期停止，贡献/尾效/表现清除 |
| 非法地面、超距、隔墙、能量 19 | 拒绝，无新区域/成本 |

**能力需求**：合法地面与圆形成员查询、独立区域和周期、成员贡献与离开尾效、跨目标 Reset 清理。
