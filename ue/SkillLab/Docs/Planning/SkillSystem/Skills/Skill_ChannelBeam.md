# Skill_ChannelBeam 引导光束

## 文档定位与状态

本文是 SkillLab 当前批次的独立技能设计稿，负责本技能的操作意图、目标、阶段、参数、效果、表现和验收。

- 具体公共能力由 `Infrastructure/` 及当前批次基建需求提供。
- 程序实现读取本技能文档、项目事实和程序线公开接口；本文件不规定 GAS 类、C++ 文件、Blueprint 或最终配置载体。
- 下文数值与交互均为建议默认值，待用户 review、程序核对和实际试玩验证。


**体验与操作**：按住装配槽位键预览方向，保持按住时左键确认。角色停止移动、锁定方向，经前摇引导光束；松开键停止。AI/Test 使用同一会话的开始/停止语义。

| 参数 | 建议值 |
|---|---|
| 输入/执行/关系 | Direction + 持续按住 / Channel 直线带查询 / Enemy |
| 启动/每段成本 | SkillEnergy 10 / 5；开始检查至少 15 |
| 冷却/前摇/引导/收招 | 4 秒 / 0.2 秒 / 2 秒 / 0 秒 |
| 段数/间隔/伤害 | 4 段 / 0.5 秒 / 每目标每段 12 |
| 长度/宽度 | 900 / 100 厘米 |
| 原点/方向 | 每段取施法者位置，方向保持确认快照 |

**阶段与成本**：激活成功仅扣启动 10 并启动冷却。引导相对 0、0.5、1、1.5 秒执行四段，区间 [开始, 开始+2 秒)。每段先检查会话/施法者/资源，再扣 5、查询并按该段 UnitId 去重；多目标和空段都只扣该段一次。实际段索引与效果分别追踪。

**终止规则**：松开、明确取消或移动命令为 Cancelled；受伤结算实际生命损失或护盾吸收大于 0、控制阻塞、死亡、Reset 为 Interrupted。段资源不足 Interrupted，原因 InsufficientResource，当段不执行；已发生伤害保留。引导中固定移动与方向，终止后恢复输入。预览时松开仅取消预览；确认要求仍按住。会话捕获 SkillId/CastId，换装不会重定向后续松开；失焦取消，重复终止幂等。

**表现需求**：实际线带边界预览、前摇、光束开始/停止、各段命中、能量和失败原因；光束循环绑定 Cast，终止时停止计时和持续反馈。

| 验收操作 | 预期 |
|---|---|
| 能量 100、两个生命 200 敌人完整四段站内 | 能量 70，各生命 152，段 1～4，同 Cast |
| 首段后、第二段前松开 | 能量 85，生命 188，后续停止 |
| 开始能量 15 / 14 | 15 时首段后资源 0，第二段前中断；14 时开始拒绝 |
| 每段间目标进出/改变鼠标 | 每段按当前范围；方向快照 |
| 普通有效受伤、护盾吸收、移动、死亡、Reset | 按上述终态停止后续段/光束，保留已结算结果 |
| 全段空范围 | 扣 30，正常完成，四个 0 命中结果 |
| 换槽位松开、失焦、重复终止 | 原会话正确结束一次，无误调用 |

**能力需求**：持续输入会话、分段推进与成本、受伤门控、线带查询、分段结果、生命周期反馈及 Player/AI/Test 会话。
