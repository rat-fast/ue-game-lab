# Skill_Barrier 护盾

## 文档定位与状态

本文是 SkillLab 当前批次的独立技能设计稿，负责本技能的操作意图、目标、阶段、参数、效果、表现和验收。

- 具体公共能力由 `Infrastructure/` 及当前批次基建需求提供。
- 程序实现读取本技能文档、项目事实和程序线公开接口；本文件不规定 GAS 类、C++ 文件、Blueprint 或最终配置载体。
- 下文数值与交互均为建议默认值，待用户 review、程序核对和实际试玩验证。


**体验与操作**：按槽位预览并点自身/友方，立即显示护盾容量；受伤先吸收、剩余扣生命；耗尽或到期时状态消失。

| 参数 | 建议值 |
|---|---|
| 输入/执行/关系 | Target、Unit / UnitTarget + 持续效果 / Self、Ally 集合 |
| 成本/冷却/阶段 | SkillEnergy 15 / 4 秒 / 前摇收招均 0 |
| 距离/视线 | 800 厘米 / 要求 |
| 容量/时长 | 50 / 5 秒，从应用成功开始 |
| 重施 | 同目标公共护盾组 Replace，新容量 50、新时长 5 秒 |

**结算与存续**：应用成功后 Cast Completed，护盾效果独立存续。先检查效果合法性，再计算待吸收伤害、护盾吸收与生命损失。本批伤害均可吸收。耗尽/到期/替换分别记录 Depleted/Expired/Replaced；新应用失败保留旧容量与时长。目标死亡/销毁、场景 Reset 清除；施法者完成后死亡保留护盾自身存续。主动移除效果经公共入口；原 Cast 终态保持。

**表现需求**：友方/自身高亮、护盾添加/容量变化/移除；容量和时长来自真实效果，循环绑定效果身份，Cast 完成后继续，移除即清理。

| 验收操作 | 预期 |
|---|---|
| 生命 200、护盾 50，受伤 30 | 容量 20，生命 200 |
| 剩余 20 再受伤 30 | 吸收 20，生命 190，Depleted 一次 |
| 新护盾受伤恰好 50 | 生命不减，护盾耗尽 |
| 等 5 秒 / 剩余 20 时由另一已授予单位重施 | 到期 Expired；重施容量 50、计时重启、旧 Replaced |
| 新应用阻塞 | 旧护盾保持，失败结果可查 |
| 敌方、死亡、超距目标或能量 14 | 拒绝，无新成本/护盾 |
| 施法者死亡、目标死亡、Reset | 前者仍存续；后两者移除并清理表现 |
| 到期与伤害同刻 | 按公共优先级先过期，伤害扣生命，结果可复现 |

**能力需求**：护盾组、吸收与 Replace、实际结果、独立效果生命周期、目标死亡和跨单位清理。
