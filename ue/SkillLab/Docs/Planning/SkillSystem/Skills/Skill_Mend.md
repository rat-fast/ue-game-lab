# Skill_Mend 治疗术

## 文档定位与状态

本文是 SkillLab 当前批次的独立技能设计稿，负责本技能的操作意图、目标、阶段、参数、效果、表现和验收。

- 具体公共能力由 `Infrastructure/` 及当前批次基建需求提供。
- 程序实现读取本技能文档、项目事实和程序线公开接口；本文件不规定 GAS 类、C++ 文件、Blueprint 或最终配置载体。
- 下文数值与交互均为建议默认值，待用户 review、程序核对和实际试玩验证。


**体验与操作**：按装配槽位键预览，左键选择自身或友方存活单位，立即治疗并显示实际生命变化。满血也可施放，提示实际恢复 0。

| 参数 | 建议值 |
|---|---|
| 输入/执行/关系 | Target、Unit / UnitTarget / Self 与 Ally 集合 |
| 成本/冷却 | SkillEnergy 15 / 3 秒；激活成功提交 |
| 前摇/收招 | 0 / 0 秒 |
| 距离/视线 | 800 厘米 / 要求；自身满足 |
| 治疗 | 40，截断到最大生命 |

**运行规则**：目标校验 → 激活/提交 → 释放重检 → 统一治疗 → 结果/表现 → Completed。记录名义量、实际恢复、溢出及新生命。满血为 Applied、实际 0、说明 NoChange。错误阵营、死亡、缺身份、超距/阻挡、资源或冷却不满足均在开始前拒绝；开始后失效按公共规则终止并保留成本。同步完成的效果保留结果；Reset 恢复场景初值。

**表现需求**：合法性高亮、释放闪光/音效、实际治疗与生命变化；预览取消清除高亮，实际 0 有无变化反馈。反馈从公共事件与真实属性读取。

| 验收操作 | 预期 |
|---|---|
| 友方生命 120/200，能量 100 | 生命 160、能量 85、冷却 3 秒；一次效果 |
| 友方生命 180/200 | 恢复 20、溢出 20，生命 200 |
| 自身满血 | 恢复 0，提交成本/冷却，NoChange |
| 敌方、死亡、未初始化、超距、隔墙单位或能量 14 | 拒绝原因可查，无新成本/效果 |
| 预览取消、重复结束、Reset 后再放 | 无误治疗、终态一次、重置后新身份 |

**能力需求**：单位目标关系、同步阶段、治疗实际值与 NoChange 结果、生命反馈、统一来源与可追踪记录。
