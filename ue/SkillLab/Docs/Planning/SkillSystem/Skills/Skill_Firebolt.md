# Skill_Firebolt 火焰弹

## 文档定位与状态

本文是 SkillLab 当前批次的独立技能设计稿，负责本技能的操作意图、目标、阶段、参数、效果、表现和验收。

- 具体公共能力由 `Infrastructure/` 及当前批次基建需求提供。
- 程序实现读取本技能文档、项目事实和程序线公开接口；本文件不规定 GAS 类、C++ 文件、Blueprint 或最终配置载体。
- 下文数值与交互均为建议默认值，待用户 review、程序核对和实际试玩验证。


### 1. 设计意图与可玩结果

点选一个敌人，经过短前摇发出可见的追踪火焰弹，命中后造成伤害并短暂减速。玩家能分辨目标选择、发射、飞行、命中和减速结束；冷却结束后可再次施放。

火焰弹作为本批六个技能之一，验证输入、投射物、生命变化、减速与可见反馈的组合。技术样本继续承担共同请求和资源链的回归。

### 2. 建议操作与阶段

1. 玩家默认槽位 Q 装配火焰弹；按 Q 进入单位目标预览，鼠标指向单位时显示合法性。
2. 左键确认敌人并提交请求。Esc 或右键单击取消预览；输入消费与右键拖动镜头按项目当前输入规则处理。
3. 通过施法者、授予、状态、资源、冷却、阵营、距离和视线检查后，开始 Cast，扣一次资源并启动冷却。
4. 前摇期间停止当前导航移动并面向已确认目标。目标身份保持为确认时的对象。
5. 前摇结束重检目标、距离和视线，通过后创建追踪投射物。生成时记录发射点、ObjectId 和 CastId。
6. 弹体向目标当前受击位置飞行。释放后施法者可移动，鼠标移动不更换目标。
7. 碰撞产生候选，经统一命中检查后依次应用伤害、减速，记录各自实际结果。
8. 命中、阻挡、失效、到期或被终止后销毁弹体；本样本 Cast 在弹体结束并完成清理后进入终态。

第 8 步是本样本建议的生命周期选择，便于第一轮取消和清理。持续效果有自己的存续期；能力模型中投射物可独立于 Cast 存续的能力仍由后续样本需求检验。

### 3. 首轮试玩参数

| 内容 | 建议值 | 语义与调整入口 |
|---|---|---|
| SkillId | `Skill_Firebolt` | 内容身份 |
| 输入/目标/模板 | Target / Unit / Projectile | 单位选择与投射物执行分开 |
| 目标关系 | Enemy | 初始化且存活、可选中的敌方单位 |
| 启动资源 | SkillEnergy 10 | 激活成功时扣除一次 |
| 冷却 | 2 秒 | 激活成功时开始 |
| 前摇/收招 | 0.2 秒 / 0 秒 | 前摇后释放，弹体结束时完成 |
| 施法距离 | 1000 厘米 | 提交与释放时检查施法者到目标中心的水平距离 |
| 视线 | 要求 | 提交与释放时检查技能阻挡物 |
| 飞行方式 | 追踪确认目标 | 始终保持同一目标身份 |
| 速度/碰撞半径 | 1200 厘米/秒 / 30 厘米 | 弹体沿追踪路径进行扫掠碰撞 |
| 飞行时间/路径上限 | 2 秒 / 1200 厘米 | 先达到的上限触发无命中结束 |
| 伤害 | 30 | 目标生命实际减少值受公共效果规则约束 |
| 减速 | 30%，持续 2 秒 | 单独可追踪的持续状态 |
| 命中次数 | 1 | 本投射物最多结算一次命中 |

飞行阶段按弹体时间和路径上限约束，施法距离仅用于提交与释放。目标释放后移动出 1000 厘米仍可能被命中；目标超过弹体有效行程时弹体到期。这一区分落实原需求中的“离开有效范围”，供用户试玩确认。

### 4. 命中与效果规则

- 目标在释放时必须仍为初始化、存活、可选中且符合敌方关系的单位。失效后以结构化原因结束当前 Cast；已开始的成本和冷却沿公共默认保留。
- 飞行中目标死亡、销毁或关系转为非法时，弹体立即停止并销毁，记录无合法命中的原因。
- 弹体扫掠与确认目标碰撞时产生候选；技能阻挡物使弹体销毁并记录 Blocked。其他战斗单位对本样本弹体透过，目标保持锁定。
- 一次合法命中首先结算伤害，再对仍存活的目标尝试减速。两种效果分别返回 Applied、Immune、InvalidTarget、Blocked 或 Failed 等结果。
- 伤害按公共效果入口结算，生命下限为 0；死亡由单位生命周期处理。已结算伤害保留结果。
- 减速效果创建独立追踪身份，保存施法者、目标、SkillId 与 CastId。基准速度 600 厘米/秒时，单独受此状态影响的速度为 420 厘米/秒。
- 同一目标再次受到该样本减速时保持 30% 强度，刷新到最近一次成功应用后的 2 秒；来源更新为最近成功应用并记录刷新事件。
- 减速在到期、目标死亡或场景 Reset 时移除。Cast 正常完成或施法者在命中后死亡时，已应用减速持续到自己的结束条件。
- 此刷新建议仅定义本样本同类减速；公共属性聚合与其他状态关系由程序提供的状态能力处理。

### 5. 取消、打断、死亡与清理

| 情况 | 首轮建议结果 |
|---|---|
| 预览取消 | 清理预览，资源与冷却保持原值 |
| 激活前拒绝 | 返回 Rejected 与原因，资源、冷却和 Cast 保持未开始状态 |
| 前摇中提交移动命令或明确取消 | 结束为 Cancelled；清理前摇与待生成对象，保留已支付资源和冷却 |
| 飞行中明确取消该 Cast | 销毁投射物，结束为 Cancelled |
| 施法者前摇/飞行中死亡 | 停止阶段、销毁弹体，结束为 Interrupted |
| 普通受伤 | 继续运行；阻止施法的控制状态按技能中断声明处理 |
| 释放重检失效 | 结束为 Interrupted，原因记录目标失效、距离或阻挡 |
| 飞行中目标失效 | 销毁弹体，Cast 正常结束并记录无命中及原因 |
| 命中、阻挡或到期 | 销毁弹体；Cast Completed，命中与效果结果另行记录 |
| 场景 Reset | 中断活跃 Cast、销毁弹体、清除本轮减速与表现，恢复单位初始属性、资源与冷却 |

右键单击在前摇中按移动输入形成取消后移动；预览阶段取消预览并消费该次点击。飞行阶段移动与明确取消分开。运行中取消接口由程序提供，测试入口可直接调用同一取消语义。

重复碰撞和重复终止只产生一次正式命中、一次 Cast 终态与一次对象销毁结果。资源、伤害、状态和反馈始终从其拥有模块产生事件。

### 6. 表现线交接

以下名称是事件语义，程序映射到公共事件契约；每项携带对应 SkillId、RequestId、CastId、ObjectId 或效果身份。

| 时机 | 玩家应看到的反馈 | 结束与绑定要求 |
|---|---|---|
| 预览 | 合法敌人高亮、非法目标原因 | 确认、取消或死亡时清除 |
| 前摇开始 | 角色朝向目标与短施法反馈 | 取消/打断时停止 |
| 释放/对象创建 | 可见弹体从角色发射位置出现 | 视觉位置跟随真实弹体 |
| 命中与效果结果 | 命中闪光、目标生命变化 | 生命显示读取实际结果 |
| 减速添加/刷新 | 目标状态标记、可观察的移速降低 | 到期/死亡/Reset 清除标记 |
| 冷却/拒绝 | Q 槽位冷却与失败原因 | 读取公共可用性 |
| 对象销毁/终态/Reset | 清除飞行表现与未结束施法反馈 | 以真实对象/状态身份关联 |

首轮使用清晰可辨的占位弹体、命中反馈和状态标记完成体验链。资源缺失须有诊断，并提供可见占位；正式美术可在同一绑定入口替换。

### 7. 程序需要提供的能力与配置语义

| 需求 | 使用模块/字段语义 |
|---|---|
| 单位目标输入、取消与原因提示 | 敌方单位目标、预览确认和取消能力 |

| 追踪投射物、阻挡、单次命中、清理 | 投射物、空间命中和对象清理能力 |
| 伤害与可刷新减速状态 | 伤害、状态持续与刷新能力 |
| 可见弹体、命中、状态与 UI | 预览、命中和状态反馈能力 |

### 8. 可执行验收例子（待运行）

基准场景：玩家 SkillEnergy=100；敌人生命=200、基础移速=600；敌人初始距离约 600 厘米；有一个友方单位与一面技能阻挡墙。实际测试单位支持生命、阵营和移速观察。

| 场景与操作 | 预期结果 |
|---|---|
| Q、点敌人、正常命中 | 能量 90；冷却开始；前摇后出现弹体；生命 170；移速 420，2 秒后恢复 600；弹体消失 |
| 预览后 Esc 或右键单击 | 预览消失；能量 100、无新增冷却与 Cast |
| 对友方、死亡单位、超距或隔墙单位直接请求 | Rejected，原因可区分；资源与冷却保持原值 |
| 能量设为 9，或冷却中再次请求 | Rejected；数值和已有冷却继续原状态 |
| 前摇中目标死亡或移动到 1000 厘米外 | 释放重检失败；已支付资源保留；终态与失败原因可追踪 |
| 前摇中移动/取消，或施法者死亡 | 依规则 Cancelled/Interrupted；后续弹体与效果停止 |
| 飞行中目标移动至施法距离外但仍可追及 | 在弹体有效时间/路径内碰撞则合法命中 |
| 飞行中目标死亡、被移除或弹体撞墙/到期 | 弹体销毁；无新效果；记录对应无命中原因 |
| 重复碰撞或重复终止回调 | 生命只减少 30，正式命中与终态只出现一次 |
| 目标生命设为 20 后命中 | 生命归零、进入死亡；减速应用结果记录目标已死亡 |
| Test 入口在已命中约 1 秒后调用同一减速应用能力 | 强度保持 30%，剩余时间刷新到 2 秒，刷新事件关联新来源 |
| 在前摇、飞行、减速存续时分别执行场景 Reset | 无残留弹体、状态或表现；恢复初始数值和冷却，再施放得到新身份 |
| Player/AI/Test 提供相同目标与参数 | 从请求开始结果语义一致，来源分别记录 |
| 把伤害改为 40、速度改为 900 并校验后运行 | 生命实际减少 40，弹体速度可观察变化，复用同一执行与效果能力 |

可玩证据包含玩家实际操作的 PIE 路径与画面，以及对应日志/事件中的资源、目标、效果和清理结果。逐项记录通过、失败或待运行；建议默认值和设计稿完成均不能代替运行证据。
