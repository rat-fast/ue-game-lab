# 06：终止、所有权与 Reset

## 目的

本文定义公共运行状态由谁拥有，以及取消、打断、死亡、目标失效、对象销毁和 Reset 的清理不变量。它不重新选择技能专属终止条件；具体技能案负责声明某个事件采用 Cancelled、Interrupted 或正常完成。

## 所有权

| 状态/对象 | 业务拥有者 | 其他层允许做什么 |
|---|---|---|
| 槽位与操作意图 | 输入/装配层 | 更新、确认、取消；不能直接施加效果 |
| 请求与 Cast | 请求/生命周期层 | 接受统一终止；不能被表现伪造成功 |
| 目标快照与命中去重 | 目标/空间层 | 提供查询和结果；不能拥有效果状态 |
| 投射物、区域、引导对象 | 执行对象层 | 按来源 Cast 终止、查询和清理 |
| 生命、资源、护盾、减速、治疗 | 效果/属性层 | 应用、刷新、移除、报告实际结果 |
| 动画、UI、日志、占位表现 | 反馈/观测层 | 订阅事实、按身份清理；不能决定逻辑 |

## 终止不变量

1. 一个 Request 只有一个对外终态；一个 Cast 只有一次 Completed、Cancelled 或 Interrupted。
2. 终止入口必须幂等；重复调用不重复扣费、命中、应用效果、销毁对象或发布终态。
3. 取消和打断只停止尚未发生的阶段；已经发生的即时伤害/治疗/护盾吸收结果默认保留。
4. 目标失效必须停止依赖该目标的后续效果，但不伪造新的成功命中。
5. 对象销毁必须清理自己的计时、表现和成员贡献，并保留来源身份和销毁原因。
6. 死亡或场景 Reset 禁止新请求，并向本单位拥有的活跃 Cast、对象、效果和表现发送终止/清理信号。

## Reset 顺序

```text
禁止新请求
→ 终止活跃 Cast/会话
→ 销毁投射物、区域和其他对象
→ 移除本单位拥有的持续效果与对外贡献
→ 清理预览、计时、表现和临时装配
→ 恢复属性、资源和冷却初值
→ 发布 ResetCompleted
```

Reset 后再次施放必须产生新 Request/Cast/对象/效果身份；旧身份不能复用。

## 技能与公共层边界

技能文档声明“什么事件终止本技能”以及已发生结果是否保留；本文保证终止过程、身份关联、清理顺序和幂等性。技能不能跳过统一 Reset、伪造终态或让表现层独立决定清理。

## 公共验收入口

至少验证前摇取消、引导停止、目标死亡、施法者死亡、区域到期、护盾耗尽、主动移除、重复终止和 Reset。验收应检查无残留对象/状态/表现，且已发生效果没有被错误重复或回滚。
