# 07：公共能力验收

## 目的

本文只验证 Batch01 基建是否足以承载六个技能，不替代各技能文档中的体验、数值和表现验收。每项测试都应记录入口、参数、运行事实、结果身份和清理结果。

## 验收矩阵

| 编号 | 公共能力 | 代表场景 | 通过条件 |
|---|---|---|---|
| A01 | 激活门控 | 资源不足、冷却中、未授予 | Rejected；无 Cast、扣费、冷却和效果副作用 |
| A02 | 输入请求 | Unit/Ground/Direction 预览确认和取消 | 请求目标/方向/位置快照正确；取消无正式副作用 |
| A03 | 来源一致 | Player、AI、Test 提交同一技能 | 业务结果一致，Source 只影响追踪 |
| A04 | 目标关系 | Self、Ally、Enemy 混合目标 | 关系不符被拒绝，合法目标可继续 |
| A05 | 空间查询 | 扇形、圆形、直线带和投射物扫掠 | 候选、命中、效果三层结果可区分；多组件不重复 |
| A06 | 目标重检 | 预览后目标死亡/移动/被阻挡 | 正式阶段重新检查并返回结构化原因 |
| A07 | 投射物 | Firebolt 飞行、碰撞、到期 | 单次命中、对象销毁和 Cast 终态只发生一次 |
| A08 | 区域 | BurnField 周期、成员进出、到期 | 周期按当前成员结算，区域和减速贡献都能清理 |
| A09 | 引导会话 | ChannelBeam 分段、松开、资源不足 | 分段成本和伤害一次，停止后不再推进 |
| A10 | 实际效果 | Mend、Firebolt、Barrier | 治疗实际/溢出、伤害实际、护盾吸收/剩余伤害可读取 |
| A11 | 持续状态 | 减速、护盾、区域成员贡献 | 添加、刷新/替换、到期/耗尽/移除原因正确 |
| A12 | 终止与 Reset | 取消、打断、死亡、重复终止、Reset | 无残留对象/状态/表现；终态和清理幂等 |
| A13 | 反馈事实 | 缺少表现资源或仅日志运行 | 逻辑结果不受影响，事件和诊断仍可追踪 |

## 技能验收的边界

A01–A13 只证明公共能力存在。Firebolt 的具体追踪速度、Mend 的 40 点治疗、ArcStrike 的 90 度、BurnField 的四次周期、ChannelBeam 的四段和 Barrier 的 50 容量，必须回到各自技能文档验收；公共验收不能以“某个技能跑通”替代全部能力证据。

## 证据要求

每个用例至少记录：输入来源、SkillId、Request/Cast/Object/Effect/State 身份、关键阶段、实际数值或状态、终止原因和 Reset 后结果。未运行的项目标记为待运行，文档完成不等于验收通过。
