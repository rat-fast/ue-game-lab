# 04：执行对象与生命周期

## 目的

本文定义一次技能开始后，Cast、投射物、区域和引导会话如何运行、关联和结束。它不选择某个技能的速度、尺寸、周期或表现资源。

## 公共对象

| 对象 | 来源技能 | 业务职责 |
|---|---|---|
| Cast | 全部 | 代表一次已开始的技能运行，拥有阶段、支付、结果和终态 |
| ProjectileObject | Firebolt | 保存追踪目标、飞行上限、命中去重和来源 Cast |
| AreaObject | BurnField | 保存位置、范围、周期、成员贡献和来源 Cast |
| ChannelSession | ChannelBeam | 保存方向、分段进度、停止原因和来源 Cast |
| PersistentEffect | Firebolt/Barrier/BurnField | 独立于 Cast 结束后继续存续，拥有自己的到期/耗尽/替换 |

每个对象都有可追踪身份并回指 SkillId、施法者和 CastId。槽位替换不能改变既有对象归属。

## 生命周期公共规则

1. Cast 只有在统一激活成功后创建；失败请求不得创建伪 Cast。
2. Cast 可经历前摇、释放、引导、收招或完成；技能文档选择具体阶段。
3. 投射物和区域可以在 Cast 完成后继续运行；Barrier 的护盾效果在 Cast 完成后独立存续。
4. 对象终态只能发布一次；重复碰撞、计时、销毁或终止回调不得重复效果。
5. 对象结束不自动代表效果成功；命中、效果应用和状态移除各自有结果。
6. 对象创建失败、目标失效、阻挡、到期和主动移除都必须带原因。

## 阶段与对象关系

- Firebolt：Cast 前摇后创建投射物；投射物结束后 Cast 完成。
- BurnField：Cast 前摇后创建区域；区域独立运行，原 Cast 可先完成。
- ChannelBeam：Cast 与 ChannelSession 同生共终；每段共享同一 CastId。
- Barrier：Cast 完成后 PersistentEffect 独立到期、耗尽或替换。
- ArcStrike/Mend：可在同步效果完成后直接结束 Cast，但仍需保留结果和幂等清理。

## 终止传播

施法者死亡、目标失效、控制阻塞、明确取消、失焦或 Reset 通过统一生命周期入口传播到对应 Cast/对象。技能文档决定某种情况是取消、打断、正常无命中完成还是对象独立继续；公共层负责执行一次终止、清理计时和发布事实。

## 公共验收入口

至少验证投射物、区域、引导会话和持续效果的独立身份与生命周期；Cast 结束后区域/护盾仍按规则存续；重复终止只一次；对象清理不会重复命中、扣费或发布终态；Reset 能找到并终止本单位拥有的全部对象。
