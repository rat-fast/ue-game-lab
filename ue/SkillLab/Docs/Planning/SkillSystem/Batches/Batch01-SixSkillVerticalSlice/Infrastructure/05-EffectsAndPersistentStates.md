# 05：效果与持续状态

## 目的

本文定义伤害、治疗、护盾、减速和周期状态怎样通过统一效果语义返回实际结果。本文不规定某技能的数值、最终属性公式或技术载体。

## 统一效果结果

每次效果应用至少区分：请求量、实际量、目标、来源技能、Cast/对象身份、结果状态和失败/移除原因。`Applied` 表示实际业务修改已发生；候选命中、目标解析成功或对象创建成功不能代替 `Applied`。

公共结果至少支持：`Applied`、`NoChange`、`Immune`、`InvalidTarget`、`Blocked`、`Failed`，以及持续状态的 `Added`、`Refreshed`、`Replaced`、`Depleted`、`Expired`、`Removed`。

## 效果类型

| 类型 | 技能 | 公共要求 |
|---|---|---|
| 伤害 | Firebolt、ArcStrike、BurnField、ChannelBeam | 生命实际减少、零值和目标死亡结果 |
| 治疗 | Mend | 实际恢复、溢出、满血 NoChange |
| 护盾 | Barrier | 容量、吸收、剩余伤害、耗尽、到期、替换 |
| 减速 | Firebolt、BurnField | 强度、持续、刷新/贡献聚合、移除 |
| 周期效果 | BurnField、ChannelBeam | 周期序号、当前目标、空周期和来源 |

## 固定业务规则

- 伤害、治疗和护盾必须记录名义量与实际量；生命下限、最大生命和护盾容量由统一属性效果规则执行。
- 护盾吸收后剩余伤害才能进入生命效果；护盾耗尽、到期和替换必须是独立状态终态。
- 满血治疗仍可完成，实际恢复为 0 且结果为 NoChange，不伪装为未施放。
- 持续状态必须拥有自己的身份和结束条件；Cast 完成不自动移除它。
- 同一来源/同一技能的刷新、替换、叠加或聚合策略由技能文档选择；公共层保证结果、来源和清理一致。
- 已发生的即时效果默认不因后续取消、打断或 Reset 回滚；持续状态按拥有者和技能规则清理。

## 所有权边界

效果层拥有已应用效果、容量/剩余时间、周期序号和移除结果；目标层只提供目标事实；输入层不能直接写属性；表现层只能读取实际结果。

## 公共验收入口

至少验证伤害、治疗、护盾和减速的实际结果；治疗溢出和 NoChange；护盾吸收与剩余伤害；持续状态到期、耗尽、替换、目标死亡和 Reset；多区域/多段结果按技能规则独立记录。
