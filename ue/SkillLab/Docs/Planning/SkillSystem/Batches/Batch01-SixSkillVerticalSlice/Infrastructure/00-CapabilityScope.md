# 00：Batch01 公共能力范围

## 目的

本文是范围总表。它只说明当前共享基线复用什么、Batch01 新增什么、每项新增能力由哪些技能提出，以及哪些规则必须留在技能文档。

## 1. 当前共享基线复用

Batch01 假定共享基线已经提供以下已确认业务能力：

- 有效战斗单位的初始化、身份和基本属性/资源容器；
- 技能授予和已授予关系检查；
- 统一技能请求入口、请求结果和基础 Cast 终态；
- Self 或指定 Unit 目标的基本解析；
- 基础资源与冷却门控；
- 一次性效果应用和结构化效果结果；
- 基础事件/日志可追踪能力；
- 单位死亡与 Reset 的基础通知。

本文不重新定义上述能力；后续文档只定义本批对它们的扩展要求。

## 2. 本批新增或扩展的公共能力

| 编号 | 公共能力 | 来源技能 | 本批要达到的业务结果 |
|---|---|---|---|
| C01 | 激活、资源和冷却时序扩展 | 全部，Beam 最高 | 区分开始成本、分段成本、拒绝无副作用和已开始后成本保留 |
| C02 | 输入意图、目标预览和统一请求 | 全部，Beam 额外需要会话 | 支持单位、地面、方向和持续会话；Player/AI/Test 共用请求语义 |
| C03 | 关系、目标快照和空间查询 | Firebolt/Mend/Barrier/ArcStrike/BurnField/Beam | 支持 Self/Ally/Enemy、单位/地面/方向、扇形/圆形/直线和去重 |
| C04 | 执行对象和异步生命周期 | Firebolt/BurnField/Beam/Barrier | 投射物、区域、引导会话和独立持续效果能在 Cast 结束后继续或终止 |
| C05 | 实际效果和持续状态 | 全部 | 伤害、治疗、护盾、减速、周期效果返回实际值、溢出/吸收、NoChange 和移除原因 |
| C06 | 所有权、终止与 Reset 扩展 | 全部 | 取消、打断、目标失效、死亡、重复回调和 Reset 可幂等清理 |
| C07 | 事实事件、诊断和公共验收 | 全部 | 表现、日志、Test 能读取真实请求、对象、效果、状态和终态事实 |

## 3. 留在技能文档的内容

以下内容不提升为公共规则：具体技能数值、输入按键、Firebolt 的追踪策略、ArcStrike 的扇形角度、BurnField 的周期时刻、ChannelBeam 的分段数量和 Barrier 的 Replace 组。公共层只提供这些选择所依赖的能力。

## 4. 不属于本批范围

长期目标中的更大能力方向不因出现在长期目录就自动进入本批。只有六技能验收确实需要的能力才在本批实现；新增公共能力必须能回链到至少一份技能文档，并在 `07-SharedAcceptance.md` 有独立验收。
