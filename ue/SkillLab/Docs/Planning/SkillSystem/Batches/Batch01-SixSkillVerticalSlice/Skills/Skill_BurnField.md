# Skill_BurnField 烬地

## 文档定位与状态

本文只定义烬地的地面目标、区域对象、周期伤害、成员减速和清理规则。公共请求、地面合法性、空间查询、效果状态、对象生命周期和 Reset 由本批基建提供；本文不指定实现方式。

状态：首批技能规则稿。数值为首轮默认值；区域独立存续、周期时刻、成员更新和清理条件是本技能验收规则。

## 1. 体验与操作

按槽位键显示圆形地面预览，鼠标位置决定落点，左键确认。经过前摇后在确认位置创建区域。区域创建后施法者可以移动和施放其他技能，区域不跟随施法者。

预览取消、非法地面、距离/视线失败或资源不足不创建区域。确认时保存位置快照；生成时重新检查可行走地面、距离、视线和位置有效性。

## 2. 配置

| 项目 | 本技能规则 |
|---|---|
| 输入模式 | Ground；槽位键预览，左键确认，Esc/右键取消 |
| 目标关系 | Enemy |
| 执行形态 | 圆形持续区域 |
| 资源 / 冷却 | SkillEnergy 20 / 5 秒，激活成功时支付和开始 |
| 前摇 | 0.2 秒；区域创建后原 Cast 结束 |
| 距离 / 半径 | 1000 厘米 / 250 厘米 |
| 存续 | 创建时起 4 秒，区间 `[创建, 创建+4秒)` |
| 周期 | 创建时刻、+1、+2、+3 秒 |
| 伤害 | 每区域、每周期、每目标 10 |
| 减速贡献 | 区域成员 20%；离开尾效 0.5 秒 |

多个区域分别结算伤害；减速贡献按公共聚合规则取最强贡献，不因本技能区域重叠而叠加百分比。

## 3. 运行时序

1. 预览显示落点、半径、地面、距离和视线提示。
2. 左键确认并提交地面位置快照。
3. 通过授予、状态、资源和冷却检查后创建 CastId、扣费并开始冷却。
4. 前摇中移动或明确取消结束为 Cancelled；死亡或 Reset 为 Interrupted。
5. 前摇结束重新检查地面、距离、视线和位置；通过后创建 AreaObjectId。
6. 区域创建成功后 Cast 发布 Completed；区域对象保存来源 CastId、施法者和 SkillId，独立运行。
7. 每个周期先确认区域存续，再查询当前成员、过滤并按 UnitId 去重，结算伤害和减速贡献。
8. 到期、主动移除、施法者死亡或 Reset 时停止周期，清除本区域贡献、尾效和表现，发布对象终态。

## 4. 成员、伤害与尾效

- 成员使用目标当前位置与圆形范围判断；边界采用公共空间容差，预览与正式查询一致。
- 目标必须已初始化、存活、敌方且可选中；视线阻挡按每次周期查询。
- 进入区域不立即造成额外伤害，等待下一次周期；离开后减速贡献转为 0.5 秒尾效。
- 尾效结束、目标重新进入、死亡、销毁或关系失效时清理/刷新对应贡献。
- 每区域每周期每 UnitId 一次；多个区域产生多个独立伤害结果。
- 区域创建失败属于已开始后的失败：保留成本和冷却，不产生 AreaObjectId，Cast 记录失败终态。

## 5. 终止、死亡与 Reset

| 情况 | 结果 |
|---|---|
| 预览取消/失焦 | 无正式请求副作用 |
| 确认前拒绝 | Rejected，不扣费、不启动冷却 |
| 前摇中移动/明确取消 | Cancelled，不创建区域，已支付成本保留 |
| 前摇中死亡/Reset | Interrupted，不创建区域 |
| 创建后施法者移动/施放其他技能 | 区域继续，位置不变 |
| 施法者死亡 | 停止其区域并清除贡献；原 Cast 已完成 |
| 到期/主动移除 | 停止周期，清除贡献、尾效和表现 |
| 周期与移除同时发生 | 先处理移除，未开始周期不结算 |

Reset 必须终止本施法者拥有的区域，并清理其施加到其他单位的减速贡献和尾效；已发生伤害不回滚。

## 6. 表现与验收

区域循环表现绑定 AreaObjectId，减速标记绑定效果身份，周期命中读取真实效果结果。区域、状态和 Reset 的清理必须分别可观察。

| 场景 | 通过条件 |
|---|---|
| 敌人全程站内 | 四次各 10 伤害，4 秒后区域销毁、速度恢复 |
| 第 0 次后进入 | 只从下一周期开始受伤 |
| 第 2 次前离开 | 已发生伤害保留，尾效 0.5 秒后移除 |
| 两个区域重叠 | 各自结算伤害，减速取最强贡献 |
| 创建后施法者移动 | 区域位置不变，周期继续 |
| 非法地面、超距、隔墙、资源不足 | Rejected，不创建区域 |
| 到期、主动移除、死亡、Reset | 无残留周期、状态或表现 |

## 7. 待评审项

- 区域创建失败的对外终态名称；
- 不同技能减速贡献的聚合优先级；
- 尾效期间重新进入是否立即刷新贡献。
