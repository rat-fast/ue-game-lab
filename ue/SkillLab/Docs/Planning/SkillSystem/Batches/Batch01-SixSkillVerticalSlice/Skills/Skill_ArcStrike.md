# Skill_ArcStrike 扇斩

## 文档定位与状态

本文只定义扇斩的具体业务规则。公共请求、敌我关系、空间查询、效果应用、生命周期和 Reset 由本批基建提供；本文不规定技术实现。

状态：首批技能规则稿。数值可在试玩中调整，但方向快照、释放时查询、每单位单次命中和终止规则必须按本文验收。

## 1. 体验与操作

按槽位键进入扇形预览，鼠标方向决定预览方向。左键确认方向；角色停止移动并朝向确认方向，经过前摇后完成一次挥斩并进入收招。确认后鼠标移动不能改变本次方向。

预览取消、失焦、目标上下文失效或开始前检查失败不产生正式施法、成本或冷却。

## 2. 配置

| 项目 | 本技能规则 |
|---|---|
| 输入模式 | Direction；槽位键预览，左键确认，Esc/右键取消 |
| 目标关系 | Enemy |
| 执行形态 | 一次性扇形查询 |
| 资源 / 冷却 | SkillEnergy 15 / 3 秒，激活成功时支付并开始 |
| 前摇 / 收招 | 0.25 秒 / 0.15 秒 |
| 范围 | 释放时半径 450 厘米，水平全角 90 度 |
| 原点 / 方向 | 释放时施法者地面位置 / 确认时水平方向快照 |
| 伤害 | 每合法目标 25 |
| 命中次数 | 每 Cast、每 UnitId 一次 |

## 3. 运行时序

1. 预览显示扇形、方向和合法性提示。
2. 左键确认并提交方向快照。
3. 通过授予、状态、资源和冷却检查后创建 CastId、扣费并开始冷却。
4. 前摇期间停止移动并保持方向；移动命令或明确取消结束为 Cancelled。
5. 前摇结束取施法者当前位置执行一次扇形候选查询。
6. 候选经过初始化、存活、敌方关系、可选中、阻挡和边界检查；按 UnitId 去重。
7. 对每个合法目标应用一次伤害；无目标也正常完成并记录零命中。
8. 进入收招，收招结束发布 Completed；收招取消不撤销已经发生的伤害。

## 4. 目标与命中

- 释放时使用水平距离和水平夹角判断，边界使用公共空间容差；预览和正式查询必须一致。
- 确认后的方向固定，但施法者位置取释放瞬间位置；目标移动到释放时的位置重新参与判断。
- 多碰撞组件只产生一个正式命中。候选、命中和效果应用分别记录。
- 目标非法不产生伤害；空范围仍支付一次成本并完成。

## 5. 终止与 Reset

| 情况 | 结果 |
|---|---|
| 预览取消/失焦 | 无 Cast、无资源和冷却副作用 |
| 开始前拒绝 | Rejected |
| 前摇中移动/明确取消 | Cancelled，不查询、不伤害，已支付成本保留 |
| 前摇中死亡/控制阻塞/Reset | Interrupted，清理前摇和表现 |
| 普通受伤 | 继续运行，除非造成公共状态阻塞 |
| 重复碰撞/重复终止 | 一次命中、一次伤害、一次终态 |

Reset 终止活跃阶段、清理表现并恢复资源和冷却；已发生伤害不回滚。

## 6. 表现与验收

必须提供预览扇形、前摇、挥斩、目标命中和收招清理反馈，并读取真实方向、范围、CastId 和效果结果。

| 场景 | 通过条件 |
|---|---|
| 两个敌人距离 300、偏角 ±20 度 | 各受 25 伤害，共同 CastId |
| 友方、隔墙、超半径或超半角 | 被过滤，无伤害 |
| 多碰撞组件 | 每个 UnitId 只受一次 |
| 确认后移动鼠标 | 仍按确认方向查询 |
| 空范围 | 扣费并完成，命中数为 0 |
| 前摇取消、死亡、Reset | 无伤害或保留已结算结果，终态和表现清理正确 |

## 7. 待评审项

- 收招期间是否允许预输入；
- 被控制状态的具体标签集合。
