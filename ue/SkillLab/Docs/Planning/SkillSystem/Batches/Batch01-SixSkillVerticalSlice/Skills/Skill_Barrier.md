# Skill_Barrier 护盾

## 文档定位与状态

本文只定义护盾的目标、应用、吸收、替换、存续和清理规则。公共请求、属性效果、伤害入口、持续状态和 Reset 由本批基建提供；本文不指定实现载体。

状态：首批技能规则稿。容量、时长和数值是首轮默认值；吸收顺序、替换和清理属于本技能验收规则。

## 1. 体验与操作

按槽位键进入单位目标预览，选择自身或友方存活单位并确认。护盾立即出现在目标身上，显示容量和剩余时间。目标关系、距离、视线、资源和冷却在开始前检查；新护盾应用失败时旧护盾保持不变。

## 2. 配置

| 项目 | 本技能规则 |
|---|---|
| 输入模式 | Target / Unit；Self 或 Ally |
| 执行形态 | 立即应用、独立持续效果 |
| 资源 / 冷却 | SkillEnergy 15 / 4 秒，激活成功支付和开始 |
| 前摇 / 收招 | 0 / 0 秒 |
| 距离 / 视线 | 800 厘米 / 要求；Self 自动满足 |
| 初始容量 / 持续 | 50 / 应用成功起 5 秒 |
| 同组重施 | 同目标本技能护盾 Replace；新容量 50，时间重启 |

同一目标同一护盾组只保留最新护盾；新应用失败不能替换旧护盾。伤害吸收和剩余生命损失必须分别记录实际值。

## 3. 运行时序

1. 预览显示目标关系、距离和视线。
2. 确认并提交目标快照。
3. 通过授予、状态、资源、冷却和目标检查后创建 CastId、扣费并开始冷却。
4. 释放前重新检查目标仍有效；有效则应用护盾。
5. 应用成功后发布容量、持续时间、替换信息和效果身份，Cast Completed。
6. 受到伤害时先读取当前护盾组，按本次伤害扣容量，再把剩余伤害交给生命效果。
7. 容量归零发布 Depleted 并移除；到期发布 Expired；重施成功先发布旧护盾 Replaced，再创建新护盾。

## 4. 吸收规则

- 伤害小于容量：容量减少伤害，生命不变，护盾保持。
- 伤害等于容量：容量归零并移除，生命不变。
- 伤害大于容量：护盾归零并移除，剩余伤害扣生命；两部分分别记录。
- 多来源伤害按公共效果入口的确定顺序逐次结算，不能重复读取同一容量。
- 目标死亡、销毁或 Reset 立即移除；施法者死亡不影响已成功护盾。
- 护盾表现读取真实容量和移除原因，不能因 Cast 完成提前停止。

## 5. 终止、替换与 Reset

| 情况 | 结果 |
|---|---|
| 预览取消/失焦 | 无请求、资源和冷却副作用 |
| 开始前拒绝 | Rejected；旧护盾保持 |
| 应用前目标失效 | 已开始则 Interrupted；不生成新护盾，成本保留 |
| 新护盾应用失败 | 旧护盾容量和剩余时间不变 |
| 施法者死亡 | 已成功护盾继续自身生命周期 |
| 目标死亡/销毁 | 护盾移除并清理表现 |
| Reset | 清除本轮护盾和表现，恢复初始属性与冷却 |
| 重复移除/重复伤害回调 | 一次扣除和一次移除终态 |

## 6. 表现与验收

添加、容量变化、替换、耗尽、到期和清理均绑定效果身份；表现不能把 Cast 终态当作护盾终态。

| 场景 | 通过条件 |
|---|---|
| 容量 50，受伤 30 | 剩 20，生命不变 |
| 剩 20，受伤 30 | 吸收 20，生命减 10，Depleted 一次 |
| 受伤正好 50 | 生命不减，护盾耗尽 |
| 等待 5 秒 | Expired 并清理 |
| 成功重施 | 旧护盾 Replaced，新容量 50、时间重启 |
| 新应用被拒绝 | 旧护盾不变 |
| 施法者死亡 | 护盾继续到期/耗尽 |
| 目标死亡或 Reset | 护盾和表现清理，无残留 |

## 7. 待评审项

- 是否允许不同来源护盾同时存在；
- 同时到达伤害的固定优先级；
- 护盾容量的 UI 呈现方式。
