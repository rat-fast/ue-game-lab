# Skill_ChannelBeam 引导光束

## 文档定位与状态

本文只定义引导光束的持续输入、会话、分段结算、资源和中断规则。公共请求会话、方向目标、空间查询、效果应用、终止和 Reset 由本批基建提供；本文不规定技术实现。

状态：首批技能规则稿。分段数量、时间、资源和伤害为首轮默认值；方向锁定、分段顺序和中断条件属于本技能规则。

## 1. 体验与操作

按住槽位键进入方向预览；保持按住时左键确认方向。确认后角色停止移动并锁定方向，经过前摇开始引导。松开槽位键、明确取消或移动命令停止引导。AI/Test 使用同一会话的开始、维持和停止语义。

预览阶段松开只取消预览。确认后会话捕获 SkillId、方向和 CastId；换装不能改变后续停止对象。

## 2. 配置

| 项目 | 本技能规则 |
|---|---|
| 输入模式 | Direction + HeldSession |
| 目标关系 | Enemy |
| 执行形态 | 固定方向直线带分段查询 |
| 启动成本 | 10 SkillEnergy，激活成功支付 |
| 分段成本 | 每段 5，查询前支付 |
| 开始最低资源 | 至少 15；不足则开始前拒绝 |
| 冷却 | 激活成功开始，4 秒 |
| 前摇 / 引导 | 0.2 秒 / 2 秒 |
| 分段 | 引导开始相对 0、0.5、1、1.5 秒，共 4 段 |
| 直线带 | 长 900、宽 100 厘米 |
| 伤害 | 每目标每段 12 |
| 原点 / 方向 | 每段施法者当前位置 / 确认时方向快照 |

## 3. 运行时序

1. 预览显示方向和直线带。
2. 左键确认，在仍按住槽位键的条件下提交会话请求。
3. 通过激活检查后创建 CastId、支付启动成本并开始冷却。
4. 前摇期间停止移动、保持方向；松开、移动命令或明确取消在引导前结束为 Cancelled。
5. 前摇结束进入 Channeling，按四个预定时刻推进分段。
6. 每段先检查会话、施法者和资源，再支付 5；资源不足时不执行该段，整个会话 Interrupted(InsufficientResource)。
7. 每段用当前位置和方向快照查询直线带，按 UnitId 去重，对当前合法敌人结算 12 伤害。
8. 四段完成后 Completed；提前停止、失焦、死亡、控制阻塞或有效受伤停止后续段。

## 4. 分段与目标

- 每段独立计算目标；目标可在段间进出直线带。
- 查询使用当前距离、敌方关系、存活、初始化、可选中和阻挡规则；鼠标移动不改变方向。
- 同一段多个碰撞组件只造成一次伤害，不同段可以再次命中。
- 空段仍支付该段成本并记录零命中。
- 造成生命实际损失，或护盾实际吸收量大于 0，才算有效受伤并中断；实际值为 0 的效果不触发。
- 已结算段结果保留，终止只停止后续段。

## 5. 终止、会话与 Reset

| 情况 | 结果 |
|---|---|
| 预览松开 | 取消预览，无成本和冷却 |
| 确认后前摇中松开/移动 | Cancelled，仅启动成本已支付 |
| 引导中松开/明确取消 | Cancelled，已结算段保留 |
| 有效受伤、控制阻塞、死亡 | Interrupted，停止后续段 |
| 某段资源不足 | Interrupted(InsufficientResource)，该段不执行 |
| 失焦或 Reset | 终止一次，停止光束、计时和后续段 |
| 换装后松开 | 结束原会话，不调用新槽位技能 |
| 重复停止/重复计时回调 | 一次终态，不重复扣费或伤害 |

终止后恢复移动和转向输入；已应用伤害和已支付成本不回滚。

## 6. 表现与验收

光束循环绑定 CastId，每段命中反馈绑定段序号和效果身份；终止时停止循环、清理瞄准线和剩余计时。

| 场景 | 通过条件 |
|---|---|
| 能量 100、两个敌人全程在内 | 总消耗 30，每目标 4×12 |
| 首段后松开 | 消耗 15，只有首段伤害 |
| 开始能量 15 | 启动和首段成功，下一段前资源不足中断 |
| 开始能量 14 | 开始前拒绝，无成本、冷却或 Cast |
| 目标段间进出 | 只在对应段命中，方向不变 |
| 有效受伤、死亡、Reset | 后续段停止，已有结果保留、表现清理 |
| 全段无目标 | 支付分段成本并完成，四个零命中结果 |
| 换槽位、失焦、重复停止 | 原会话只结束一次 |
