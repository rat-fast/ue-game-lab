# Skill_Mend 治疗术

## 文档定位与状态

本文只定义治疗术的具体业务规则：输入意图、目标关系、施法时序、治疗结果、表现和验收。公共请求、目标合法性、效果应用、生命周期和 Reset 由本批基建提供；本文不规定 GAS、C++、Blueprint 或最终配置载体。

状态：首批技能规则稿。数值为首轮默认值，需通过试玩确认；目标关系、实际值记录和满血结果属于本技能验收规则。

## 1. 体验与操作

按装配槽位键进入单位目标预览，鼠标指向自身或友方存活单位，左键确认并立即施放。自身可直接作为 Self 目标；友方必须满足距离和视线。Esc、右键单击、失焦或目标上下文失效只取消未提交预览。

确认时捕获 SkillId、施法者、目标 UnitId 和装配快照。确认后目标移动或鼠标变化不能改写已经提交的请求；释放前仍需再次检查目标。

## 2. 配置

| 项目 | 本技能规则 |
|---|---|
| 输入模式 | Target / Unit；Self 或 Ally |
| 执行形态 | 同步单体效果 |
| 资源 / 冷却 | 激活成功扣 SkillEnergy 15 / 开始 3 秒 |
| 前摇 / 收招 | 0 / 0 秒 |
| 距离 / 视线 | 800 厘米 / 要求；Self 自动满足 |
| 名义治疗 | 40 |
| 目标 | 已初始化、存活、可选中的自身或友方单位 |

技能配置可调整资源、冷却、距离和名义治疗量，但不能改变请求拒绝无副作用、实际治疗单独记录以及满血仍可施放的规则。

## 3. 运行时序

1. 预览显示目标关系、距离、视线和可施放提示。
2. 左键确认并提交目标快照。
3. 检查施法者初始化、授予、状态、资源、冷却及目标关系；失败返回 Rejected。
4. 激活成功后创建 CastId、扣资源并开始冷却。
5. 释放时重新检查目标仍有效；有效则通过统一治疗入口应用 40 点名义治疗。
6. 记录请求量、实际恢复量、溢出量、应用前后生命和效果状态。
7. 即使实际恢复为 0，也发布 Applied/NoChange 结果并结束 Cast 为 Completed。

## 4. 治疗结果

- 实际恢复量为 `min(名义治疗, 最大生命 - 当前生命)`，不能超过最大生命。
- 溢出量为名义治疗减实际恢复量；满血时实际恢复 0、溢出 40、状态为 Applied、原因为 NoChange。
- 目标在释放前死亡、销毁、未初始化、关系不符、超距或被阻挡时，已开始施法以目标失效终止并保留已支付成本；不产生治疗。
- 治疗效果结果必须与 Cast 终态分开记录；Cast Completed 不等于实际恢复大于 0。
- 同一 Cast 只应用一次治疗；重复回调不得重复恢复生命。

## 5. 取消、打断与 Reset

| 情况 | 结果 |
|---|---|
| 预览取消/失焦 | 无请求、资源、冷却或 Cast |
| 开始前检查失败 | Rejected；资源和冷却不变 |
| 已开始但释放前目标失效 | Interrupted/目标失效；成本和冷却保留 |
| 释放完成后 | Completed；已发生治疗保留 |
| 施法者或目标死亡、Reset | 清理未完成施法和反馈；Reset 恢复属性、资源与冷却 |
| 重复终止/重复应用 | 只产生一次终态和一次治疗 |

## 6. 表现与验收

表现读取真实目标、实际治疗、溢出、NoChange 和失败原因。满血施放必须有可辨识的“无实际变化”反馈，不能伪装成未施放。

| 场景 | 通过条件 |
|---|---|
| 友方生命 120/200 | 生命变为 160，能量减 15，冷却开始 |
| 友方生命 180/200 | 实际恢复 20，溢出 20，生命为 200 |
| 自身满血 | 实际恢复 0，结果为 Applied/NoChange |
| 敌方、死亡、未初始化、超距、隔墙、能量 14 | Rejected 或目标失效，无新治疗 |
| 预览取消、重复结束、Reset 后再施放 | 无误治疗，终态一次，Reset 后新请求独立 |

## 7. 待评审项

- 目标在提交后、释放前移动出距离时，统一采用 Interrupted 还是 Rejected 的对外原因；
- 溢出量是否显示给玩家；
- 友方关系是否包含召唤物或临时单位。
