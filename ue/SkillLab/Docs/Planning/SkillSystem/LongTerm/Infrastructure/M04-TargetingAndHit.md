# M04 目标与命中需求

## 状态与职责

建议稿，待 review。公共语义见 [基建入口](README.md)。本模块解析目标、提供预览、查询/过滤候选、确认命中与去重。

## 目标与查询规则

- 支持自身、单位、地面、方向以及单位列表/范围结果；允许关系以 Self/Ally/Enemy/Neutral 集合表达。
- 单位目标捕获身份，地面捕获位置，方向捕获水平非零归一化向量。输入确认与真正命中分开，实际查询重新检查。
- 地面来自射线命中与可行走位置；投影修正上限和地面超距处理由批次或游戏规则声明。
- 形状覆盖圆、扇形、直线带及扩展形状；中心水平位置判定和高度差上限由规则声明。
- 圆按中心距离；扇形按距离/夹角；矩形直线带纵向 [0, 长度]、横向绝对值不超过半宽。
- 距离/角度容差和边界是否包含由规则声明；预览与正式查询必须使用同一参数与坐标规则。
- 候选过滤身份、初始化、存活、当前关系、可选中、范围与视线；形状输入合法性与后续单位过滤分别执行。
- 视线按技能要求检查施法者/查询中心到目标或地面中心的技能阻挡物；单位是否阻挡查询由规则声明。
- 效果免疫按效果类别由 M05 检查，区别于空间命中和目标非法。
- 每次施法/对象/段/周期按单位去重；同单位多个碰撞组件算一次，下一轮可重新命中。
- 投射物的碰撞是候选；候选仍走统一过滤。飞行有效距离由发射策略和对象上限表达，区别于施法起始距离。

## 业务输入输出与依赖

输入为目标规格、确认上下文、关系/形状/视线策略、候选与段/周期。输出为预览形状与合法性、解析目标、测量与过滤原因、合法命中和去重结果。

M01 输入确认，M02 提供身份/关系，M03 提供阶段上下文，M06 提供碰撞/成员候选，M05接收合法命中。预览候选不替代真正命中。

## 可调项

距离、形状尺寸、角度、允许关系、视线、锁定/重新选择、失效处理、重复命中范围均可由内容声明；程序公开支持的组合。

## 独立验收

- 单位/位置/方向解析与非法零方向、地面失败、错关系原因可区分。
- 代表性圆、扇形和直线带查询各有内外/边缘例子，具体尺寸由批次参数提供。
- 隔墙、死亡、不可选中目标过滤；确认后移动目标按执行时位置判断。
- 同单位多组件本轮一次，下轮可重中；多个合法目标逐个返回。
- 预览尺寸与实际判定一致，玩家/AI/Test 参数相同规则一致。
