# 长期基建能力地图

## 定位

本目录汇集技能系统的长期公共能力候选，供后续批次选择和拆解。下列规则和模块内容是长期策划候选，不代表当前共享基线已经承诺，也不代表某一批必须全部实现。

每个批次先提出技能需求，再从技能场景中抽取可复用能力；批次范围优先于本目录中的宽泛候选。长期能力要进入某批，需在该批技能与基建文档中明确范围、业务语义和验收。

长期目标入口见 [LongTerm README](../README.md)，当前首批见 [Batch01](../../Batches/Batch01-SixSkillVerticalSlice/README.md)。
