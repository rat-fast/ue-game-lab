# M09 内容访问与运行诊断需求

## 状态与职责

建议稿，待 review。本模块让人和工具能确认技能内容可用、运行事实可追踪、能力缺口可交接；不替代运行模块执行技能，也不把日志当作第二套事实来源。

## 内容访问

- 内容必须能表达技能身份、目标需求、阶段/执行形式、资源与冷却、空间参数、效果/状态组合、表现引用和单位可用技能集合。
- 内容访问前检查身份唯一、引用存在且启用、目标与执行形式匹配、数值和时间合法、周期/持续表现可结束、取消/死亡/Reset 有归属、所需能力处于可用状态。
- 非法引用、未支持执行形式、缺失终止策略和跨层能力缺口返回具体诊断，不通过隐藏脚本绕过。配置载体、字段名和版本格式由程序接口决定。

## 运行诊断

至少可追踪请求来源、技能、单位、施法、阶段、资源/冷却、目标候选与实际命中、效果实际值、状态/对象生命周期、取消/打断/完成、Reset 和残留拥有者。日志记录运行事实，不重新推断状态。

## 交接与生产

技能策划定义玩家可观察语义和参数意义；程序提供能力目录、接口、载体、校验和运行证据；技能侧代码组合公共能力并保留来源、版本、依赖和变更摘要。发现无法表达的能力时，记录需求、影响范围、验收样本和是否改变公共契约，转入程序线评估。

## 独立验收

- 替换技能的伤害、范围、速度或状态参数能通过校验并影响运行；非法引用和不支持组合得到具体诊断。
- 运行报告区分设计完成、能力可用、技能实现、表现接入和运行结果，并能回到样本参数与复现步骤。
- Reset 报告按拥有者列出对象、状态、冷却和表现残留；同一事实不被日志层重复生成。
