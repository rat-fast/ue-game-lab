# M06 空间与持续执行需求

## 状态与职责

建议稿，待 review。公共语义见 [基建入口](README.md)。本模块承载空间执行和持续对象，产生命中候选，按生命周期终止。

## 执行能力

| 形式 | 业务输入 | 业务输出与结束 |
|---|---|---|
| 直接/单位 | 来源上下文、目标、释放时点 | 查询/候选与执行完成 |
| 瞬时范围 | 原点、方向、形状尺寸、当前段 | 候选与一次执行结果 |
| 投射物 | 发射点、锁定/方向、速度/半径、时间/路径上限、阻挡策略 | 创建、扫掠碰撞候选、阻挡、命中数/到期/失效结束 |
| 持续区域 | 固定/跟随中心、范围、时长/周期、成员策略 | 独立对象、进入/离开/周期候选与销毁 |
| 引导/多段空间调用 | 阶段发来的本段上下文与形状 | 本段候选与执行结果 |
| 位移 | 移动者、起终点/方向、速度/时长、阻挡与中断 | 移动过程、候选、到达/阻挡/停止 |

候选交 M04 过滤，合法命中交 M05 效果。段推进与成本由 M03执行，空间对象保留明确来源。

## 持续与对象规则

- 投射物扫掠运行路径，按声明追踪锁定目标或固定方向，真实对象位置驱动反馈。
- 时间与累计路径上限取先到达者；阻挡、目标失效、命中上限、取消、源死亡与 Reset 分别有策略。
- 区域可在源施法完成后继续运行，保存独立身份与来源，仍能按对象/源单位定位移除。
- 周期伤害与成员维持分开表达：进入/离开提供成员事实，周期提供每轮候选。
- 成员检测的更新时机与轮询上限由规则声明；离开尾效由效果模块管理。
- 持续执行在包含开始、不包含结束的区间按序号触发。首轮偏移可声明为 0 或延迟。
- 模拟暂停时周期/段暂停；帧延迟跨时点时按序处理，每轮重检当前世界并记录预期/实际时点。终止先于尚未结算工作。
- 对象销毁幂等、停止计时/监听/候选与持续反馈；源施法已完成时保持原终态。
- 位移遵守碰撞、存活与控制；阻挡结果和停止位置可查，其完成与整次施法终态分开。

## 业务输入输出与依赖

输入为来源/阶段、空间和时间参数、命中次数、对象存续/终止策略。输出为创建、候选、阻挡/失效/到期、对象完成与清理回执。

技术载体、碰撞通道与计时组织由程序接口确定；技能声明其所需策略和参数。

## 独立验收

- 固定/追踪弹体速度、扫掠、单次命中与上限结束准确。
- 持续对象按声明时长、周期和首偏移执行，结束时不追加越界周期。
- 成员进出、失效与尾效使用真实事实；多组件候选由 M04 去重。
- 源施法完成后区域仍运行，源死亡或 Reset 可定位并清理。
- 引导停止后无后续空间调用；位移阻挡/死亡/取消有明确终止。
