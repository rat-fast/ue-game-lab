# M02 战斗单位与能力基础需求

## 状态与职责

建议稿，待 review。公共语义见 [基建入口](README.md)。本模块提供单位身份、关系、属性环境、技能资格和死亡/重置通知。

## 单位与关系

- 单位具有稳定身份、阵营、生命/资源/状态、技能可用集合与实际授予记录。单位可以由多种运行对象承载。
- 关系先识别自身 Self；同阵营其他单位为 Ally；敌对阵营为 Enemy；中立关系为 Neutral。允许关系以集合表达。
- 输入阵营改变后，目标查询与效果读取当前关系并触发失效处理。
- 生命、资源、速度和自动恢复由调用方单位模板提供；模块只保证基础值、当前值、最大值及其重置语义可区分。

## 生命周期与授予

1. 生成时建立身份/关系，初始化属性与状态，授予默认能力，再应用装配，最后通知可用。
2. 重复初始化不叠加属性、标签或授予；返回已有状态或明确重复原因。
3. 授予保存技能与来源、是否临时和装配资格；可用集合区别于全项目目录。
4. 撤销使未开始请求失效、槽位清理；已开始内容按所声明策略停止或完成。
5. 死亡立即禁止新请求，通知运行、对象、效果与输入拥有者处理。死亡可保留对象供观察，区别于销毁。
6. 复活/Reset 通过明确模板恢复存活、位置/朝向、属性/资源与能力；恢复范围由调用模式表达。
7. 场景 Reset 协调所有单位与跨目标输出效果，完成条件包括无残留和初值恢复，见公共规则。

## 业务输入输出与依赖

输入为单位模板、阵营关系、技能资格与授予/撤销、死亡/重置操作。输出为有效身份、初始化结果、关系查询、可用集合、属性/状态环境和生命周期通知。

各模块负责自己拥有内容的清理并向本模块回执。存储、引擎类、组件与运行能力归属由程序接口提供。

## 可调项与开放问题

初始属性、关系、默认授予、复活策略和 Reset 保留装配可调；复活的持续状态保留策略需由实际游戏规则确认。

## 独立验收

- 自身、同阵营、敌方、中立四类关系准确；缺身份/未初始化目标不能参与效果。
- 重复初始化与 Reset 无重复授予和属性叠加。
- 临时技能撤销后槽位与未开始请求失效，实际状态可见。
- 死亡禁止新请求；复活/重置后重新具备资格。
- 两单位之间的持续输出在源或目标 Reset 时能正确定位并清理。
