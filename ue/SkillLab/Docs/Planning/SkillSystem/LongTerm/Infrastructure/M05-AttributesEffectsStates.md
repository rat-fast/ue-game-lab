# M05 属性、效果与状态需求

## 状态与职责

建议稿，待 review。公共语义见 [基建入口](README.md)。本模块处理资源/数值、伤害治疗护盾、持续状态、叠加刷新、免疫驱散和结果。

## 数值与效果

- 属性区分基础、当前、最大与派生值；资源参与启动/持续支付。修改来源可追踪，Reset 恢复初始环境。
- 效果输入来源、目标、参数与条件，输出应用结果、实际值及持续移除凭据。
- 伤害先检查合法性/免疫与已支持的减伤，再算待吸收量、护盾吸收、生命损失与新生命。生命下限 0，致死通知单位生命周期。
- 治疗截断至最大生命，报告名义、实际、溢出。合法满血应用成功、实际 0，说明无变化；死亡目标不治疗。
- 护盾保存剩余容量和结束时间；护盾组、替换条件和失败保留策略由规则声明。
- 吸收=min(剩余容量, 待吸收量)，剩余扣生命；耗尽、过期、替换、死亡/Reset 均移除并报告原因。
- 伤害事实包含实际生命损失与吸收，用于受伤中断；生命不减但护盾吸收仍为有效受伤。

## 持续状态与组合

- 支持伤害、治疗、护盾、属性/资源修改、状态添加/移除；增减益、控制、驱散、免疫及周期效果在支持清单中表达。
- 持续/周期效果声明时长、首触发、间隔、来源、叠加组、层数与移除条件，瞬时效果保留结果记录。
- 可支持拒绝、刷新、替换、叠层与独立实例；刷新说明强度是否覆盖，叠层说明上限，独立实例各计时。
- 减速等属性状态可按来源贡献追踪；聚合方式、移除后的重算和基础值恢复由规则声明。
- 来源按目标状态组刷新，或按对象/目标维持独立贡献；区域内维持可附离开尾效，源移除清除贡献及尾效。
- 组合效果按声明顺序独立返回；前项致死后后项重新检查目标。伤害免疫与状态免疫分别报告。
- 状态到期/移除、目标死亡、源条件与 Reset 各按明确策略处理。已完成施法不自动清除独立状态。
- 控制类别声明阻塞移动/能力、免疫与驱散类别；冲突优先级与驱散筛选由受支持规则表达，新增规则带独立用例。

## 业务输入输出与依赖

输入为来源、目标、效果参数、组/刷新/移除策略与合法条件；输出为成功、免疫、目标非法、阻塞、失败，实际修改与添加/刷新/变化/移除事实。

M02 提供属性/状态环境，M03确定支付和阶段，M04提供合法命中，M06提供周期/成员事实。表现和诊断读取本模块事实。

## 独立验收

- 治疗低于最大生命时实际值和溢出正确；满血仍能返回成功且实际 0。
- 护盾分别承受小于、等于和大于容量的伤害，吸收与剩余生命损失正确，耗尽只移除一次。
- 多个减速贡献并存、移除一项和全部移除后，聚合速度与规则声明一致。
- 刷新时长、替换失败保留旧值、独立贡献各自到期可查。
- 护盾到期与伤害同刻、组合致死、免疫、跨单位 Reset 均符合公共顺序与清理。
