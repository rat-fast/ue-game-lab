# Batch01 六技能纵切片基建需求

## 定位与状态

本目录是当前第一批六个技能的**实施范围**，用于把公共模块能力收敛成一份程序可直接执行的批次需求。状态为策划建议稿，待用户 review、程序核对接口并经实际试玩验证。

本批对应的技能内容从 [六技能索引](../../../Skills/SkillDesigns.md)进入各独立技能正文，模块长期能力见 [Infrastructure 入口](../../README.md)。本目录不重新定义技能玩法，也不规定 GAS 类、C++ 文件、Blueprint、配置载体或 DSL。

## 程序读取顺序

1. 阅读本文件，确认 Batch01 的范围和交付顺序；
2. 阅读 [输入、操作意图与请求链路](InputIntentRequestFlow.md)，确认输入到请求的业务语义；
3. 阅读 [运行时状态与所有权](RuntimeStateAndOwnership.md)，确认固定规则、配置、状态和拥有者；
4. 阅读 [公共基建能力需求](CapabilityRequirements.md)，取得本批需要实现的能力子集与共同约束；
5. 阅读 [基建验收矩阵](AcceptanceMatrix.md)，取得可执行用例；
6. 只读取矩阵中列出的 M01–M09 模块段落，以及程序线的架构、接口和项目事实；
7. 技能侧实现再读取 `Skills/`，按各技能提交具体组合或能力缺口。

模块正文是长期能力目录；本批文件是当前实施选择。模块中未被本批能力需求选中的扩展，不作为 Batch01 的实现前置条件。

## 本批交付对象

- 可控制的玩家、敌方和友方单位，以及 Self/Ally/Enemy/Neutral 关系；
- 统一请求、激活、阶段、资源、冷却、取消、中断、完成和幂等清理；
- 单位、地面、方向目标，圆形、扇形、直线带、追踪投射物和持续区域；
- 伤害、治疗、护盾、减速、周期效果、来源追踪和跨单位 Reset；
- 预览、阶段、命中、实际效果值、失败原因、对象/状态生命周期反馈；
- Player、AI、Test 共用同一业务请求路径，以及可重复批量运行和诊断。

## 状态晋升

本批中的数值和默认规则均是建议值。经过程序实现、可重复运行和用户 review 后，稳定的公共语义才回写 M01–M09；只服务于本批手感或仍待确认的内容留在本批目录并标记结果。
