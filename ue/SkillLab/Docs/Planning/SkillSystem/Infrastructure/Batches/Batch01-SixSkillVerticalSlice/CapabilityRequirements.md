# Batch01 公共基建能力需求

## 文档定位

本文只定义第一批需要启用的**通用公共能力**。它不定义 Firebolt、Mend 或其他具体技能的数值、按键、技能名和特殊例外；具体技能通过独立技能文档消费这些能力。

程序可按本文拆分公共能力任务。具体技术实现、GAS 组织、C++/Blueprint 边界和数据载体由程序线决定。业务输入输出必须保留，技术载体可以变化。

## 一、能力清单

| 能力组 | 必须提供的公共能力 | 不属于本能力组 |
|---|---|---|
| 输入与意图 | 物理输入到逻辑动作、槽位解析、SkillId 捕获、操作意图、预览、确认、取消和持续会话 | 伤害、治疗、资源扣除、命中结算 |
| 单位与资格 | 单位身份、阵营关系、属性/资源环境、技能可用集合、授予/撤销、死亡与 Reset 通知 | 输入解释、空间查询、效果公式 |
| 请求与生命周期 | 请求接收、激活门控、阶段、成本/冷却提交、前台占用、取消/打断、终态和幂等清理 | 具体技能数值、具体空间形状实现 |
| 目标与空间 | Self/Unit/Ground/Direction 目标规格、合法性重检、关系过滤、空间候选、视线和去重 | 效果实际结算、表现资源播放 |
| 执行载体 | 投射物、持续区域、引导分段和其他可独立存续对象的创建、更新、终止和来源追踪 | 目标关系规则、资源扣除、效果公式 |
| 属性与效果 | 伤害、治疗、护盾、资源/属性修改、持续状态、叠加/刷新/替换、实际结果和移除 | 选择目标、输入会话、表现播放 |
| 反馈与观测 | 预览、阶段、请求、目标、实际效果、对象/状态生命周期、失败原因、缺失资源和 Reset 反馈 | 重新判断命中、重新执行逻辑 |
| 外部调用与测试 | Player/AI/Test 统一请求路径、维持/停止会话、条件设定、批量复现、Reset 和残留检查 | AI 决策本身、测试工具 UI 本身 |
| 内容校验与诊断 | 身份/引用/组合/范围/终止策略校验，能力可用性和运行结果追踪 | 用脚本绕过运行时规则 |

## 二、公共业务输入与输出

### 输入

- 来源和施法单位；
- `SkillId` 或已捕获的技能身份；
- `TargetSpec` 或由操作意图生成的目标上下文；
- 技能配置声明的阶段、资源、冷却、空间、效果和终止策略；
- 取消、维持、停止、死亡、失焦、目标失效和 Reset 等生命周期通知。

### 输出

- 请求是否被接受、拒绝或暂存，以及可读原因；
- `RequestId`、可选 `CastId`、技能身份和来源的关联结果；
- 阶段变化、支付、冷却、目标候选、实际命中和效果结果；
- 对象创建、更新、阻挡、到期、销毁和清理结果；
- 状态添加、刷新、替换、免疫、移除和实际数值；
- 取消、打断、完成、Reset 和残留诊断事实。

## 三、固定公共规则

1. 预览/意图取消不产生正式效果；请求拒绝不创建已开始施法，不产生正式资源、冷却或效果副作用。
2. 只有公共激活门控接受后，才进入已开始施法并获得 `CastId`；成本、冷却和阶段由生命周期统一提交。
3. 目标确认是输入快照，不是命中保证；释放、周期和分段需要按当前世界重新检查。
4. 命中候选、效果应用和实际数值是不同结果；空命中、免疫、目标失效和实际值为零都必须可区分。
5. 施法、执行对象、效果和状态可以独立结束；它们必须保留来源并能由来源或对象身份清理。
6. 事件、反馈和日志只读取运行事实；表现资源缺失不改变逻辑结果。
7. 终止和清理可重复调用但只产生一次业务终态；Reset 完成前必须知道残留的拥有者和原因。
8. Player、AI、Test 从统一请求开始使用同一业务规则；测试只改变初始条件和观察方式。

## 四、配置、运行时状态与实现边界

| 层级 | 由策划声明/确认 | 由程序维护 |
|---|---|---|
| 公共能力 | 能表达的业务语义、固定不变量和验收结果 | 接口、调度、对象、错误映射和技术实现 |
| 技能配置 | 输入意图、目标关系、成本、冷却、阶段、空间、效果、状态和表现选择 | 加载、校验、缓存和运行时访问 |
| 运行时状态 | 状态的业务含义和终止条件 | 当前值、计时、身份、对象存储、事件发布和清理 |

技能配置不得关闭公共激活检查、身份追踪、统一效果入口、终态幂等和 Reset 清理。

## 五、Batch01 的能力覆盖

第一批六个独立技能用于覆盖能力组合：

| 覆盖需求 | 由哪些技能作为验证样本 | 基建需要证明的公共语义 |
|---|---|---|
| 单位目标和关系 | Firebolt、Mend、Barrier | 目标身份、Self/Ally/Enemy 过滤、失效重检 |
| 方向和范围 | ArcStrike、ChannelBeam | 方向快照、扇形/直线带查询、分段重检 |
| 地面和独立对象 | BurnField | 地面合法性、区域独立生命周期、成员/周期事实 |
| 投射物 | Firebolt | 对象来源、追踪/阻挡/到期、单次命中和清理 |
| 效果与状态 | 全部涉及技能 | 伤害、治疗、护盾、减速、持续状态和实际结果 |
| 输入会话 | ChannelBeam，以及普通技能的预览 | 操作意图、确认、维持、停止、换装和失焦 |
| 反馈与诊断 | 全部技能 | 预览、阶段、实际值、失败原因、对象/状态清理 |

这些技能名只出现在覆盖关系中，不定义公共能力本身；新技能可以在不改变能力语义的情况下复用同一能力。
