# 验证与内容生产

## 单模块交接完成标准

模块只有同时满足以下条件，才称为实现交接完成：职责和排除项明确；输入输出和身份契约明确；正常、失败、取消、中断和重置行为明确；配置字段语义和固定约束明确；依赖、所有权和清理明确；至少一个样本或运行检查点；未决项不会阻塞首批实现，或已明确标记为阻塞。

## 运行验证

每个样本至少验证配置加载、单位初始化、能力授予、正常请求、资源不足、冷却、状态阻塞、目标无效、取消、打断、死亡、效果、表现、日志以及 ResetUnit 后再次运行无残留。

编译成功只证明代码可编译。运行通过必须有 PIE 日志、屏幕调试或可复现命令证据；命令行没有执行预期输入时不得标记为通过。

## 内容生产流程

意图 → 技能规格 → 配置草稿 → 配置校验 → 运行样本 → 日志/表现检查 → 人类 review → 可复用内容。

策划确定体验、范围和固定规则；程序提供加载、校验、生成和重置接口；AI 生成规格、配置和测试参数，但不能静默改变公共契约。

## 缺口报告

无法用配置表达的需求必须记录需求、现有能力、缺口原因、建议扩展、影响模块、验证样本和是否改变公共契约。不能通过每个技能的隐藏脚本绕过缺口。
