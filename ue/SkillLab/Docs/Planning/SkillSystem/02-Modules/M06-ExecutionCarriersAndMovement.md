# M06 执行载体与移动（详细设计草稿）

## 定位

M06 定义技能如何在空间中执行，包括直接释放、投射物、范围、持续区域、引导、多段和位移，以及这些临时对象的生命周期。

已确认：投射物、范围、持续区域、引导、多段、位移属于系统范围。
AI 建议默认方案：对象是否由 Actor、组件或能力任务承载交给程序映射。

## 职责

负责创建和推进空间执行对象，产生候选命中，管理持续时间、碰撞、周期和位移过程，并把结果交回 M03、M04、M05。

不负责资源扣除、阵营过滤、伤害计算或 UI 资源选择。

## 执行形式

- 直接执行：在释放阶段立即查询目标并产生命中。
- 投射物：带施法上下文飞行，在碰撞或到期时产生候选。
- 范围/扇形/直线：按释放点、方向和形状查询。
- 持续区域：在空间中存续，按进入、周期或离开规则查询。
- 引导/多段：由 M03 控制阶段，M06 执行每段空间行为。
- 位移：按技能声明移动施法者或目标，并处理碰撞、阻挡和中断。

## 生命周期

创建
→ 绑定施法实例和上下文
→ 执行碰撞/范围/周期逻辑
→ 产生候选命中
→ M04 过滤并交给 M05
→ 到期、命中次数完成、被取消或重置
→ 清理对象、计时器、监听和引用

能力结束不必销毁仍有合法存续期的投射物或区域，但对象必须保留明确归属和结束条件。

## 配置与固定约束

可配置：速度、半径、形状、持续时间、周期、最大命中数、穿透、追踪、位移距离、阻挡、创建和销毁事件。

固定约束：

- 临时对象必须关联施法实例和来源技能；
- 候选命中必须经过 M04 过滤；
- 不能由空间对象自行绕过 M05 修改属性；
- 取消、死亡和重置时必须有明确处理；
- 清理可重复调用，不产生重复命中。

程序可选择 Actor、组件、AbilityTask、碰撞通道和计时器的具体组合。

## 需要用户重点确认

- 技能结束后投射物/区域是否继续；
- 投射物默认是否穿透和多目标；
- 持续区域默认周期；
- 位移被阻挡或受击时的结果；
- 死亡和重置是否立即销毁空间对象。
