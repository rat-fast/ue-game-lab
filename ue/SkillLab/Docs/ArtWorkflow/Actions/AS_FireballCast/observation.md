# AS_FireballCast 视觉观察

**动作类型判断：双手前举的持续姿态。** 双手聚在身前，身体姿态在整段中变化很小（[page-0000.png](page-0000.png) f00000–f00011、[page-0001.png](page-0001.png) f00012–f00020）。

总览：21 个源帧，30 fps（约 0.67 秒）；图像视角为固定三分之四后侧。全段人物双脚分开站立，身体朝画面左前方，双手在胸口至肩前并拢/相对，肘部弯曲。帧间姿势变化非常小，没有清楚可见的位移、转身或完整的手臂挥动。

## 按帧观察

- **f00000–f00008（page-0000.png）**：维持站姿，双手保持在身前的聚拢姿态；头、躯干和腿部轮廓基本稳定。
- **约 f00009–f00010（page-0000.png）**：f00009 的前臂靠近肩部处出现小而亮的白色区域，手势仍几乎不变。这是本段较醒目的局部变化。
- **f00011–f00020（page-0000.png、page-0001.png）**：继续保持同一姿势；后续个别帧手臂附近仍可见亮点。

## 峰值与关键时点

- **身体/肢体动作峰值：无清晰峰值**。f00000–f00020（[page-0000.png](page-0000.png)、[page-0001.png](page-0001.png)）双手聚于身前、双脚分立的轮廓变化很小，无法可靠地选出一次最充分的伸展或独立动作峰值。
- **视觉线索峰值：f00009 及 f00017–f00018**。f00009 的 [page-0000.png](page-0000.png) 上前臂靠近肩部处有突出的白色亮点；f00017–f00018 的 [page-0001.png](page-0001.png) 在相近的手臂与肩部附近也有明显白亮区域。
