# MF_Pistol_Walk_Bwd 动作观察

**动作类型：持枪后退行走循环。** 人物保持屈肘持枪姿态，双腿以较慢节奏交替迈步，躯干呈后退方向的斜向姿态。

## 整体变化

动作是连续、较慢的后退步态，重心随左右脚交替承接而轻微转移；手臂基本保持在身前，没有独立动作阶段。
