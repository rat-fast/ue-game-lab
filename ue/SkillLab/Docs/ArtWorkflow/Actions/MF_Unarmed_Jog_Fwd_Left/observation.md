# MF_Unarmed_Jog_Fwd_Left 动作观察

**类型判断：** 徒手向前并偏左移动的慢跑循环。人物以侧后方为主，屈肘摆臂，腿部交替向前迈出；偏左方向按资产名称描述。

## 整体动作

全段是连续跑步步态，伴随轻微躯干起伏与摆臂，步态相位反复出现，没有独立停顿。
