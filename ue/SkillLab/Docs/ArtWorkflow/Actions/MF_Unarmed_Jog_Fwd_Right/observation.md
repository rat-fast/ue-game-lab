# MF_Unarmed_Jog_Fwd_Right 动作观察

**类型判断：** 徒手向前并偏右移动的慢跑循环。人物以侧后方姿态呈现，双臂屈肘摆动，双腿交替迈步；方向按资产名称描述。

## 整体动作
