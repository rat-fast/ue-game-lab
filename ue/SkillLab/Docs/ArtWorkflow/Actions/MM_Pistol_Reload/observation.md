# MM_Pistol_Reload 动作观察

**类型判断：** 双手在胸前聚拢并作连续调整的上肢操作动作。总览中未见明确武器或弹匣形状，故不把动作解释为已确认的装填事件。

## 整体动作

人物站姿基本稳定，双臂向前弯曲，双手从胸前位置相靠，随后在身体前方改变高低和相对位置；头部略随手部动作转动。下肢几乎不变。

## 峰值与关键时点

- 源帧 0–11：双手靠近上胸，手臂弯曲。证据：`page-0000.png`。
- 源帧约 12–35：双手持续在胸前调整，源帧 12–23 附近可见局部白亮，但其性质无法从图像确认。证据：`page-0001.png`、`page-0002.png`。
- 源帧约 36–60：上肢动作延续并趋于收拢。证据：`page-0003.png` 至 `page-0005.png`。
