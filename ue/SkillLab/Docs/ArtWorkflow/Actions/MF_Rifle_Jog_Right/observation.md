# MF_Rifle_Jog_Right 动作观察

**类型判断：** 持枪向右侧移步/慢跑循环。角色双手保持枪械姿势，腿部向两侧交替打开、收回，身体随步伐轻微转动。

## 整体动作

源帧 0–32（`page-0000.png`–`page-0002.png`）展示连续侧向跑步循环。前段身体较正，随后出现更明显的侧向迈步和转身角度变化；手臂持续保持在身前，没有明显武器操作动作。

## 峰值与关键时点

- **身体/肢体峰值：** 无独立单帧峰值；源帧约 12–23（`page-0001.png`）侧向跨步幅度较大，源帧 24–32（`page-0002.png`）继续交替收放。
- **颜色/白光线索：** 未见明显变化。
