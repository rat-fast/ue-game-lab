# MM_ChargedAttack 视觉观察

**动作类型判断：长时间预备后前冲的重拳样动作。** 前段保持宽站姿，之后转体、倾身并单臂前伸（[page-0001.png](page-0001.png) f00012–f00023、[page-0002.png](page-0002.png) f00024–f00035、[page-0003.png](page-0003.png) f00036–f00039）。“重”是动作力度的视觉印象。

总览：56 个源帧，30 fps（约 1.83 秒）；固定三分之四后侧视角。动作前段长时间保持宽站距、膝部弯曲、双臂横向展开的姿势；随后身体转动并收拢一侧手臂，接着向画面左侧明显前冲/迈步，最后减速并回到双臂抬起的站姿。

## 按帧观察

- **f00000–f00023（page-0000.png、page-0001.png）**：低而宽的站姿基本维持，双臂先逐渐抬起并向两侧打开，随后在胸肩高度保持，帧间姿势变化较小。
- **f00024–f00031（page-0002.png）**：躯干和肩部开始旋转，手臂由横向展开转向身前；约 f00028–f00029，身前手部附近出现亮点。到 f00031 身体明显转向，重心开始脱离原先的对称站姿。
- **f00032–f00039（page-0002.png、page-0003.png）**：动作变为连续向前的倾身步进/冲步，一只手臂伸向前方，另一只手臂收在躯干附近；身体在这一段横向位移最明显。
- **f00040–f00047（page-0003.png）**：前伸手臂收回，步幅缩小，躯干逐步抬起，手臂转为靠近胸前的防守样姿势。
- **f00048–f00055（page-0004.png）**：以屈膝、双臂抬起的稳定站姿结束；末页空白格标为无源样本，不属于动作帧。

## 峰值与关键时点

- **身体/肢体动作峰值：约 f00034–f00038**（[page-0002.png](page-0002.png)、[page-0003.png](page-0003.png)）。一臂朝画面左侧伸直，躯干明显倾斜，双腿形成较长的斜向轮廓；这一段的前伸与倾身最突出。相邻姿态接近，不能可靠选出唯一峰值帧。
- **视觉线索峰值：f00028**（[page-0002.png](page-0002.png)）。收在身前的手附近出现醒目的白色亮点，邻近帧中没有同样突出的亮点；f00021（[page-0001.png](page-0001.png)）头部也可见白亮点。
