# SkillLab 项目上下文

本目录保存进入 SkillLab 项目时通用且当前有效的事实：代码架构地图、模块职责、运行入口、调试入口和项目级 AI 研发约束。这里不放某个具体功能的临时交接记录，也不放策划规则。

所有程序 Agent 必须先读本文件，再按任务读取：

- `SkillLabCodeArchitecture.md`：项目代码地图、模块边界和主要入口；
- 与当前修改直接相关的 `Modules/<模块>.md`；
- 需要理解项目级 AI 规则时读取 `AI-NativeWorkflow.md`。

不要因为进入本目录就读取所有模块文档；只读取当前任务涉及的模块和运行入口。
