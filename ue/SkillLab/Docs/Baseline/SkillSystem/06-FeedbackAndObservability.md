# 反馈与可观察事实

## 职责

说明其他系统可观察并呈现哪些技能事实，以及事实来源边界；不规定 HUD、日志或特效的具体视觉样式。

## 当前承诺

- 请求拒绝、施法阶段、目标/命中、实际效果、持续效果周期/移除、取消和完成是语义不同的事实，不得互相替代。
- 角色表现与其他反馈只消费技能运行层产生的真实事实。动画、特效、声音、Lua 返回值或预览不能产生命中、扣费、伤害、治疗、持续效果或终态。
- 动画 Cast Notify 通过带 Tag 的 Gameplay Event 告知当前 Ability 到达释放时点；该信号本身不代表命中或效果，实际业务结果仍由权威运行机制产生。
- 缺少或延迟表现资源不改变技能业务结果；表现故障也不能补发已不存在的业务事实。

## 实现与验证

当前 Notify 已经校验后转为带身份的 Gameplay Event，由当前 Ability 接收并交 Runtime 推进正式释放；基础设施 Review 已通过。有限自动化核验了事件身份/生命周期的若干路径，NullRHI Probe 记录有限目标和效果事实。用户报告当前技能在游戏中能正常释放，作为基本游戏流程观察；它不等同于正式可见 PIE 证据，也不证明全场景行为等价或所有边界验收。覆盖与缺口见 `07-ContentBoundary.md`。
