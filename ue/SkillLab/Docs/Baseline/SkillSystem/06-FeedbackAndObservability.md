# 反馈与可观察性

## 职责

记录技能运行过程中对玩家和其他系统可观察的事实，以及当前 HUD 和临时世界反馈能够表达的内容。反馈只展示已经产生的运行结果，不拥有施法、目标、效果或清理规则。

## 当前事件事实

当前技能事件可以表达以下业务过程：

| 事件 | 业务含义 |
| --- | --- |
| `Rejected` | 请求未进入有效施法，带有拒绝原因 |
| `Started` | 施法已开始并进入前摇 |
| `TargetSelected` | 当前施法的单位或地面目标已经确定，可展示位置和范围 |
| `PhaseChanged` | 施法进入前摇、主动阶段或恢复阶段中的新阶段 |
| `Hit` | 一次执行结果；成功状态表示命中并进入效果处理，失败状态表示未命中或执行失败，并带有原因 |
| `EffectApplied` | 伤害、治疗或持续伤害效果已经被应用 |
| `DamageTick` | 持续伤害的一次周期结算已经发生 |
| `BuffApplied` | 持续效果已经附着到目标 |
| `BuffRemoved` | 持续效果已经结束或被清理 |
| `Cancelled` | 当前施法因取消、阻塞、超时、死亡或其他原因中断 |
| `Completed` | 当前施法已经正常结束 |

同一项技能可以先产生目标和阶段事件，再产生一次或多次执行结果、效果或周期伤害事件，最后以完成或取消结束。`Completed` 只表示施法生命周期结束，不单独代表伤害或治疗一定成功；具体效果事实应读取 `Hit` 或效果事件中的成功状态和实际数值。

## 事件携带的事实

每个结果事件可以关联到：

- 技能、请求和本次施法的身份；
- 施法单位与目标单位；
- 当前阶段及阶段持续时间；
- 单位命中点或地面位置，以及范围半径；
- 目标生命值变化前后的数值；
- 请求数值与实际生效数值；
- 持续效果的身份和剩余/总持续时间；
- 成功、失败和拒绝原因。

这些事实允许 HUD、日志和表现直接展示同一条技能运行链，而不需要根据画面猜测当前阶段或数值。

## 当前 HUD 能表达的内容

本地玩家拥有一个技能状态界面，当前可见信息包括：

- 当前生命值与生命上限，以及生命比例条；
- 当前能量与能量上限，以及能量比例条；
- 有效技能槽位的顺序和快捷键；
- 技能的可读名称、能量消耗；
- 技能是否准备好、剩余冷却时间和冷却进度。

当技能运行数据尚未就绪时，生命和能量区域显示未准备状态，技能槽位不会伪造运行数值。技能栏和输入使用同一份有效槽位列表，因此被过滤掉的快捷键不会出现在 HUD 中。

## 当前世界与屏幕反馈

运行事件已经连接到临时表现反馈：

- 地面目标确定时显示范围标记；
- 命中单位时显示目标标记和伤害/治疗数值；
- 周期伤害发生时显示周期伤害数值；
- 持续燃烧效果附着时显示持续状态标记和文字提示；
- 施法开始、命中、周期伤害、持续效果附着和请求拒绝可以产生屏幕消息；
- 取消和正常完成仍会发布事件，供其他表现或验证观察者使用。

这些反馈使用可替换的临时几何和文字作为当前占位表现。它们用于让目标位置、数值变化和持续状态可见，不构成正式美术、动画、音频或战斗 UI 资源契约。

## 当前业务事实

- 伤害、治疗、周期伤害、持续效果附着和移除都可以被分别观察。
- 反馈数据包含实际生效数值以及生命值前后值，能够区分“命中但数值为零”“未命中”和“请求被拒绝”。
- 当前世界和屏幕反馈以短时占位表现展示目标、数值和持续状态，不改变技能结果。

## 当前限制

- 当前没有证据表明已经建立正式的动画、音频、特效资源绑定或可供策划编辑的反馈规范。
- 屏幕消息和世界标记属于当前调试/占位反馈，不能据此承诺最终玩家体验、可访问性或本地化文本。
- 网络同步、多人观察者、回放和跨客户端事件一致性尚无验证证据。
