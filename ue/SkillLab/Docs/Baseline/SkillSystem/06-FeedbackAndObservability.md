# 反馈与可观察事实

## 职责

说明其他系统可观察并呈现哪些技能事实，以及事实来源边界；不规定 HUD、日志或特效的具体视觉样式。

## 当前承诺

- 请求拒绝、施法阶段、目标/命中、实际效果、持续效果周期/移除、取消和完成是语义不同的事实，不得互相替代。
- 角色表现与其他反馈只消费技能运行层产生的真实事实。动画、特效、声音、Lua 返回值或预览不能产生命中、扣费、伤害、治疗、持续效果或终态。
- 缺少或延迟表现资源不改变技能业务结果；表现故障也不能补发已不存在的业务事实。

## 实现与验证

当前工作树中的 CharacterPresentation 交接（2026-10-22）描述了结构化技能事件和局部 NullRHI 观察；实现文件尚有未提交修改，且没有当前可见 PIE/视口验收。SkillSystem Batch02 的完整事件覆盖、身份隔离及原生/Lua 外部行为一致性未验证。
