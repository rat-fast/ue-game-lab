# 持续效果与清理边界

## 职责

记录施法、持续效果和表现之间的业务区分，不定义运行对象归属、取消实现或重置工具流程。

## 当前承诺

- 施法动作或施法终态与独立持续效果不是同一生命周期。动作结束不证明持续效果结束。
- 持续伤害的周期结果及结束/移除事实由技能运行层产生，表现不得自行延长、结束或补造。
- 取消、完成、效果移除和系统重置是不同的运行事实；没有当前确认的规则不得推导其资源、效果或冷却后果。

## 当前实现与验证、限制

迁移后 NullRHI RuntimeProbe 记录 BurningBuff 在施法后产生三次周期伤害，随后出现效果移除和跟踪清理事实；这是一个有限运行样本，不覆盖异常或死亡清理。通用 Notify/Ability 身份校验的独立 Review 通过，但坏 reload 原子保持、缓存脚本快照行为及死亡/Reset 组合仍没有指定的自动化或运行证据。用户报告技能在游戏中能正常释放，不代表清理边界已全面验收。具体证据与限制见 `07-ContentBoundary.md`。

Reset 的精确状态恢复、取消时持续效果处理、已结算即时效果保留规则以及重复施加行为，除已确认的样本语义外均待核实/确认。
