# 输入意图与请求

## 职责

界定玩家选择技能/目标的意图与运行层正式受理请求之间的区别。本篇不承诺固定快捷键、槽位、鼠标映射、预览样式或输入缓冲行为。

## 当前承诺

- 输入层表达要使用的技能、发起者和目标意图。
- 目标候选、光标位置、范围预览和内容读取成功都不代表正式请求已受理，也不代表效果成立。
- 请求受理及拒绝事实由技能运行层产生；表现不得把输入意图显示为已命中或已结算。

## 实现与验证状态、限制

当前策划和程序材料涉及既有本地输入路径，但本基线没有将其固定映射列为跨任务业务承诺。当前未核验完整玩家输入路径，也未确认手柄、触屏、AI 输入、技能队列或自定义配装。
