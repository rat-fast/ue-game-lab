# 技能系统领域模型

## 职责

说明共享业务讨论中的核心概念，不锁定其代码类、对象拓扑、配置格式或执行实现。

## 核心概念与关系

- **单位**：可作为技能请求的发起者或技能目标。
- **技能定义**：描述一种技能及其业务选择；技能定义与单次使用不同。
- **技能资格**：某单位是否拥有使用某项技能的资格。
- **请求**：一次使用技能的尝试，包含技能、发起单位和目标意图；请求可能被拒绝。
- **施法**：请求被受理后形成的一次独立运行过程，可产生目标、命中、效果、取消或完成等事实。
- **目标**：请求指向的自身、单位或地面位置。目标被选择不等同于实际命中。
- **效果**：技能对战斗状态造成的实际业务变化，例如伤害、治疗或持续伤害。
- **持续效果**：有独立于原施法的运行期间和结束/移除事实的效果。
- **运行事件**：对上述真实发生事实的可观察表达，可供 HUD、日志或表现消费。

```text
单位 -> 技能资格 -> 技能定义
单位 -> 请求 -> 受理后的施法 -> 目标/执行 -> 实际效果 -> 状态变化
施法与效果 -> 运行事件 -> 观察与表现
```
