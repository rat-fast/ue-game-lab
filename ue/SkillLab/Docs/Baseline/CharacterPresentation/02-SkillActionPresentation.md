# 技能动作与表现事件

## 职责

定义表现消费技能真实事件及技能对象空间配置的业务边界，不定义动作资源、Notify、Slot、时长、配置 Schema 或技术接口。

## 当前承诺

- 表现读取技能运行层的真实结构化事实。请求结果、阶段、目标/命中、实际效果、持续效果、取消和完成是不同事实。
- 动作、动画通知、特效和 Lua 回调不能自行宣告施法成功、命中、扣费、效果应用或施法终态。
- 动作与对应施法关联；旧施法事件不得改变新施法的表现状态。
- 动作终止与独立持续效果分开。燃烧等持续效果是否继续或结束由技能运行事件表达。
- 缺少动作资源时不能伪造或阻断权威技能结果；具体玩家可观察降级仍未确认。

## 空间配置的当前承诺

业务来源为 [空间适配共用边界](../../Planning/CharacterPresentation/Batches/Batch04-OnDemandSpatialAdaptation/README.md)及 [空间配置需求](../../Planning/CharacterPresentation/Batches/Batch04-OnDemandSpatialAdaptation/01-SkillSpatialConfigurationSupport.md)。

- **对象与事件**：同一技能的真实投射物和不同表现对象可以有独立空间定义，只在已接入的生成或事件点消费。真实对象配置进入正式生成链；纯表现配置不产生目标、命中、伤害、治疗或持续状态事实。
- **位置与偏移**：位置可取施法者、当前目标、已有地面作用位置或显式关联对象，不重新选目标。Actor 来源可解析模型原点及适用骨骼/Socket；关联对象与目标是独立来源，缺失时不回退为目标。偏移明确选择参照局部轴、世界固定轴或技能执行方向，跟随更新继续使用所选语义。
- **方向与尺寸**：方向可取执行方向、参照朝向或明确世界朝向，与位置来源分别确定。资产视觉朝向修正和整体视觉缩放不改变投射物碰撞体、瞄准规则或实际作用范围。真实生成点移动可能改变初始轨迹和碰撞结果；视觉尺寸还依赖资源自身尺寸及反馈基准，配置比例不等于最终边长。
- **一次放置与持续跟随**：一次放置在实际触发或生成时求值，此后不因参照移动被拖动；已交付投射物按既有行为运行。适用的持续效果表现可跟随位置，方向可随参照变化或保持出现时世界朝向，视觉尺寸不无意继承参照缩放。
- **寿命、身份和失败**：持续表现依据真实效果实例及移除事实结束，动作或 Cast 结束不等于独立效果结束；一个来源的清理不能删除另一个来源的对象。参照失效时停止无效跟随并清理对应视觉对象，不撤销已生效效果。未配置空间项保持原有效路径；显式无效配置有失败反馈，不伪装为世界原点成功。纯表现失败不改技能结果，真实生成失败沿既有提交失败处理，不新增补发、自动成功或退款规则。
- **内容调整**：同类空间能力面向不同内容复用，不以四技能为白名单。同一参数或绑定保持唯一来源。配置通过启动或现有重载入口生效，新 Cast 捕获新定义，既有对象继续使用自身快照，不承诺热更新既有对象。

## 当前实现与职责分工

当前已接入事件驱动技能动作、真实投射物释放生成，以及目标选定、命中、持续效果施加事件的无碰撞表现代理。持续跟随仅用于持续效果施加的表现对象，来源限施法者或目标；资源入口限 StaticMesh。

C++ 提供受控空间求值、正式对象创建、跟随和清理；Lua 选择对象、事件与空间组合；JSON 承载可调参数、资源及模型绑定。当前 Lua 采用组合声明，不提供逐帧脚本或任意 Actor 访问，不据此承诺任意条件或空间运算能力。

实现及局部运行核验依据见 [实现摘要](../../ProgramWorkflow/CharacterPresentation/Batches/Batch04-OnDemandSpatialAdaptation/ImplementationSummary.md)、[独立 Review](../../ProgramWorkflow/CharacterPresentation/Batches/Batch04-OnDemandSpatialAdaptation/Review.md)及 [表现模块](../../ProjectContext/Modules/CharacterPresentation.md)。这些依据不代表全部动作体验或四技能空间适配通过。

## 当前限制与待确认

- 当前没有地面或关联对象持续跟随、Niagara 或材质参数配置能力，也未建设任意事件与对象的通用演出系统。
- 生产骨骼/Socket、真实释放前移动后采样、Fireball 偏移后的近墙/遮挡与重叠出生，以及不同模型/资源替换的完整复用仍未充分验证。
- 技能动作质量、Notify 与释放事件视觉时点、取消/完成后的姿势恢复、缺资源降级可读性、旧/新动作竞态及完整差异化反馈仍未全面验收。
- 空间资料导出、独立读取、AI 自主选点与调整未实现；正式动作、VFX/音频方案及最终适配参数不属于当前承诺。
