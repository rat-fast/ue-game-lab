# 效果与状态

## 职责

本篇定义技能对单位造成的业务结果、属性变化和持续状态边界。它说明伤害、治疗和持续伤害如何被理解，以及这些结果如何与施法过程和事件观察衔接。不定义效果配置格式、底层对象或具体表现资源。

## 当前承诺

当前技能效果分为三类：

- **伤害**：对目标造成一次伤害。最终扣除量会经过目标护甲处理，并且生命值不会低于零。
- **治疗**：对目标恢复一次生命。恢复后的生命不会超过最大生命。
- **持续伤害**：在一段持续时间内按固定周期对目标造成伤害。持续效果在施加成功后独立于原施法继续运行，直到持续时间结束或效果被移除。

效果结果必须区分“请求的数值”和“实际改变的数值”。伤害和治疗都可以观察应用前生命、应用后生命和实际变化量；效果没有成功应用时，不能把请求值当作已结算值。

当前属性的业务意义如下：

| 属性 | 业务意义 | 当前规则 |
| --- | --- | --- |
| 生命 | 单位当前生存值 | 夹在 0 与最大生命之间；降至 0 时进入死亡状态 |
| 最大生命 | 生命上限 | 不能为负；治疗和生命修改都受其约束 |
| 能量 | 施放技能消耗的资源 | 夹在 0 与最大能量之间；技能在释放提交前必须有足够能量 |
| 最大能量 | 能量上限 | 不能为负 |
| 护甲 | 物理伤害结算中的减免量 | 不能为负；当前伤害结算按原始伤害减去护甲并将结果限制为不小于零 |
| 强度 | 技能数值的来源属性 | 当前技能可用系数将其加入原始伤害计算 |

死亡是生命状态与技能门禁相连的公共状态。单位进入死亡状态后，当前施法会被中断，之后的技能请求也会被拒绝，直到生命恢复并移除死亡状态。

持续效果有自己的实例身份。燃烧类技能当前会对敌方单位施加持续伤害，按当前内容持续四秒、每秒结算一次；重复施加到同一目标时，当前样例只保留一个活动实例并刷新持续时间。该条是当前样例的运行行为，不能扩展为所有未来效果的统一叠加规则。

## 当前业务事实

- 无效目标或无效数值不会产生成功的命中或属性变化。
- 即时伤害会经过护甲减免和生命下限处理；治疗不会超过生命上限。
- 持续伤害建立后，会在持续期间产生周期伤害结果，并在持续结束或被清理时产生移除结果。
- 效果应用、周期伤害、持续效果添加和持续效果移除都是独立业务事实；施法完成不等于效果一定成功。

## 当前限制

- 当前只有伤害、治疗和持续伤害三种已表达的效果类型；护盾、免疫、控制、净化、吸血、暴击和复杂叠层没有当前基线承诺。
- 当前只有燃烧样例明确表达“单实例并刷新持续时间”；其他持续效果的叠加、刷新和替换规则仍未定义。
- 当前伤害类型虽有扩展入口，但现有公共结算只确认护甲减免这一条路径，不能据此承诺物理、魔法和纯粹伤害已经有不同规则。

## 待确认问题

- 后续持续效果是否统一采用单实例刷新，还是由每个效果分别决定叠加策略。
- 死亡状态下已有持续效果是否全部移除，还是允许其继续到期；当前 Reset/清理路径可以主动移除，但战斗规则尚未单独确认。
