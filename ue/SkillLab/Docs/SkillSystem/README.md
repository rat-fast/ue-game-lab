# SkillLab 技能系统共享业务基线

## 基线定位

本目录定义 SkillLab 当前技能系统的共享业务语义。它回答“系统现在承诺什么、一次技能如何运行、哪些事实可以被下游 Agent 依赖”，不描述 C++、GAS、Blueprint、组件拓扑或最终配置载体。

本轮基线按当前运行链已经表达的能力重新整理。代码和验证材料是本轮核对当前事实的来源，文档只把这些事实转换成业务概念和使用边界；未来策划方案、长期路线和未运行验证的设想不会自动成为当前承诺。

## 阅读顺序

1. `00-DomainModel.md`：单位、技能定义、请求、施法、目标、效果和事件的关系；
2. `01-InputIntent.md`：快捷键、目标选择、地面预览、确认和取消；
3. `02-RequestLifecycle.md`：请求门控、前摇、释放、执行、恢复、完成和取消；
4. `03-TargetingAndExecution.md`：自身、单位、地面目标，敌我关系和三类执行方式；
5. `04-EffectsAndStates.md`：伤害、治疗、持续伤害、属性和死亡状态；
6. `05-OwnershipAndCleanup.md`：一次施法、持续效果、表现和重置的归属与清理；
7. `06-FeedbackAndObservability.md`：可观察事件、数值结果和表现反馈；
8. `07-ContentBoundary.md`：当前内容范围、可调整内容和仍未冻结的边界。

## 当前共享承诺

- 单位可以拥有技能资格，并以自己的身份发起技能请求或成为目标。
- 一次请求必须经过施法者状态、技能资格、资源、冷却和目标条件检查；通过后才形成一次有身份的施法。
- 施法具有前摇、主动执行和恢复阶段。技能可以在主动阶段立即完成，也可以等待命中、区域查询或持续效果建立后完成。
- 当前目标形状包括自身、单位和地面位置；目标关系包括自身、友方、敌方和任意单位。
- 当前执行方式覆盖单目标即时执行、可见投射物和地面范围执行。
- 当前效果覆盖伤害、治疗和持续伤害；持续伤害在施法结束后仍可继续产生周期结果，直到持续时间结束或被清理。
- 当前技能使用生命、能量、护甲和力量等战斗属性；伤害会经过护甲减免并将生命限制在有效范围内，治疗不会超过生命上限。
- 死亡、眩晕和沉默等阻塞状态可以拒绝技能；施法开始后进入阻塞状态也会使当前施法取消。
- 目标选定、命中、效果应用、周期伤害、持续效果移除、取消和完成都可以作为结构化运行事实被观察，并可由表现层显示反馈。

## 当前四个技能样本

| 技能 | 目标与关系 | 执行方式 | 效果 | 当前业务行为 |
| --- | --- | --- | --- | --- |
| 火球 | 单位、敌方 | 投射物 | 伤害 | 投射物飞向目标；命中或被阻挡时结算，未命中会报告失败原因 |
| 区域爆发 | 地面位置、敌方 | 地面范围 | 伤害 | 在指定位置查询范围内的敌方单位，可同时影响多个目标；范围为空时报告空区域 |
| 修复 | 自身、自身 | 即时目标 | 治疗 | 对施法者进行一次治疗 |
| 燃烧 | 单位、敌方 | 即时目标 | 持续伤害 | 对目标施加持续伤害，按周期产生伤害结果并在结束或清理时报告移除 |

## 统一验证边界

本基线依据当前业务表达、已有程序证据和现有验证材料整理。现有材料支持生命周期、伤害计算、持续效果、定义内容和 HUD 构建等部分判断，但未逐项证明完整的玩家体验；鼠标投射、地面预览、碰撞表现、正式动画与 HUD 布局仍需在实际运行中确认。未逐项列出的能力不代表已经完成完整体验验收；如果运行中发现明显问题，应先修复，再重新审查本基线。网络多人、长期策划中的更多技能、复杂控制、引导和连锁效果不属于当前承诺。

## 维护边界

具体技能只补充自己的业务选择和参数，不重复定义公共生命周期、目标和效果规则。公共规则发生变化时，应先更新本目录，再同步下游文档。
