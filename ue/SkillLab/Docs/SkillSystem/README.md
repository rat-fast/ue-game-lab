# SkillLab 技能系统共享业务基线

## 基线定位

本目录是 SkillLab 技能系统当前共享业务语义来源。业务基线定义当前应承诺的语义；代码、程序文档和验证记录只用于核对当前能力、实现状态和证据，不自动决定业务规则。

当前项目方向是单机、实时、俯视角战斗，操作接近 MOBA，技能丰富度接近 ARPG。这是项目方向，不代表代码已经支持完整的目标、执行、状态或输入体验。

## 语义优先级

1. 本目录已经确认的业务基线；
2. 用户确认的项目方向和后续业务决定；
3. 代码、程序文档和验证记录提供的能力核对与证据；
4. Planning 与具体技能文档中的候选选择。

本目录不写 GAS/C++/Blueprint 类名、文件名、最终数据载体、内部调度方式或具体技能最终数值。公共规则改变时，先形成变更说明并经 review，再更新相应正文和版本。

## 阅读顺序与关系

1. `00-DomainModel.md`：领域概念、身份和对象关系；
2. `01-InputIntent.md`：当前输入来源和请求字段；
3. `02-RequestLifecycle.md`：请求校验、激活和施法链路；
4. `03-TargetingAndExecution.md`：目标校验、快照和执行方式；
5. `04-EffectsAndStates.md`：当前瞬时效果与结果；
6. `05-OwnershipAndCleanup.md`：当前归属与 Reset 清理；
7. `06-FeedbackAndObservability.md`：事件、日志和表现观察边界；
8. `07-ContentBoundary.md`：当前固定规则、定义内容和运行时边界。

具体技能只声明自己的选择和参数，不复制上述公共规则；程序文档只说明当前实现映射和证据。旧 Planning、Batch 和历史审计不能单独覆盖本基线。

## 当前基线版本与状态

版本：v0.2（2026-10-07）。

- 已确认：项目总体方向（见“基线定位”）。
- 当前程序能力：单位初始化、默认技能授予、统一请求入口、来源/目标快照、同步瞬时效果、结构化请求/效果/事件结果、资源/冷却门控和 Reset 事件。
- 当前未实现或未定义：复杂输入、空间执行、持续状态、完整取消/死亡语义、外部内容载体和对应运行证据。

各篇正文只展开自己的职责，未决项不得被下游文档当作冻结规则。
