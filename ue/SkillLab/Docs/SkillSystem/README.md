# SkillLab 技能系统共享业务基线

## 文档状态

- 状态：占位目录，正文待建立
- 定位：SkillLab 技能系统唯一持续修改的当前业务基线入口
- 适用对象：人类主控、策划 Agent、程序 Agent、表现 Agent 及相关评审者

## 使用说明

本目录只维护技能系统稳定、共享、与技术载体无关的业务语义。它不以旧策划模块划分为组织依据，也不写 GAS 类名、C++ 文件、Blueprint 结构、最终数据载体、内部调度方式或具体技能最终数值。

后续批次在本基线之上提出增量变更案，经过 review、实现和验证后，将确认的公共语义合并回本目录。具体批次、技能内容和程序技术投影分别位于项目对应目录。
