# 请求与施法生命周期

## 职责

定义当前代码已经承载的请求校验、门控、激活、资源/冷却、目标解析、效果和终态链路。

## 当前承诺

当前请求链按以下顺序执行：

```text
提交请求
→ 解析技能定义
→ 校验初始化、施法者身份、授予资格和目标
→ 检查冷却与资源
→ 激活检查
→ 激活成功后创建 CastId、扣资源并记录冷却
→ 目标解析
→ 应用效果
→ Completed 或效果拒绝后 Completed
```

开始前失败返回 `Rejected` 和原因，不创建 `CastId`、不扣资源、不启动冷却。当前成功施法是同步完成的；`Completed` 与效果是否成功分开记录。

## 当前实现与验证

当前可观察的拒绝原因包括定义缺失/禁用/无效、未初始化、施法者不匹配、未授予、目标无效、冷却和资源不足。激活成功后才创建施法身份；验证日志已观察到成功链、冷却拒绝和 Reset 后再次成功。

## 当前限制

当前没有已实现的输入缓冲、前摇、引导、周期、收招或通用取消入口。取消、死亡打断、资源退款和异步施法不构成当前承诺；相应状态枚举存在也不代表链路已支持。
