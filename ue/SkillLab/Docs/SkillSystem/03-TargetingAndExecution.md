# 目标与执行

## 职责

本页定义技能如何选择目标、确认关系与距离，以及当前四类技能行为如何把目标转化为命中和效果。目标选择与最终命中是两个阶段：施法开始时确认请求合法，释放时再次确认；投射物和范围技能随后仍可能命中阻挡物、命中多个目标或没有命中。

## 目标形状与关系

当前支持三种目标形状：

- `Self`：目标固定为施法者，不需要鼠标选中单位；
- `Unit`：目标是一个活着且已初始化的单位；
- `Ground`：目标是施法范围内的地面位置，可以进一步查询位置周围的单位。

目标关系支持自身、友方、敌方和任意单位。当前四个技能使用的关系是：Fireball 和 BurningBuff 选择敌方单位，AreaBurst 选择地面位置并影响范围内敌方单位，Mend 选择自身。敌我关系由双方单位的队伍关系判定；目标必须是有效且存活的单位。

## 单位目标确认

单位目标必须通过以下检查：

1. 目标存在且可用；
2. 目标是有效且存活的单位；
3. 目标符合技能声明的自身、友方、敌方或任意单位关系；
4. 目标与施法者的二维距离不超过技能范围。

自身技能会自动把施法者作为目标。通过鼠标选择单位时，系统先将光标解析为单位目标，再执行同一套关系、存活和范围检查；敌方技能点到施法者自身时会继续寻找光标射线上的其他单位。选择失败会报告投射失败、没有单位、关系不符、目标不可用或超出范围等原因。

## 地面目标确认

地面技能必须提供有效地面位置，位置不能包含无效数值，且与施法者的二维距离不能超过技能范围。地面位置会随请求进入施法结果和目标事件，供预览、范围标记和后续执行使用。地面位置通过确认后，释放阶段仍会再次检查位置和范围。

## 当前执行类型

### Fireball

Fireball 对一个敌方单位建立一次投射。投射物从施法者附近发出，朝目标的可用瞄准点飞行，具有速度、碰撞半径和寿命；它可以与世界阻挡物或其他单位发生解析。命中目标或被阻挡后才应用一次伤害，飞行到期、生成失败或被阻挡而没有合法目标时报告未命中并结束本次行为。投射物不会把施法者自身作为命中目标。

### AreaBurst

AreaBurst 先确认一个地面位置，再在该位置的半径内查找符合敌方关系且存活的单位。每个单位在一次范围执行中至多计入一次，然后分别应用伤害。范围内没有合法目标时报告 `AreaEmpty`，施法仍以无命中结果完成，不会虚构一个目标。

### Mend

Mend 使用自身目标立即执行一次治疗，目标不依赖鼠标单位选择。

### BurningBuff

BurningBuff 对一个敌方单位立即施加持续伤害效果。目标选择仍遵循单位目标的存活、关系和范围检查；持续伤害的周期和持续时间由效果规则处理，见 `04-EffectsAndStates.md`。

## 目标快照与异步命中

施法结果和事件会记录目标对象、目标单位、目标位置、命中结果以及数值变化。目标选择成功不等于必然命中：Fireball 的飞行过程可能被阻挡或过期，AreaBurst 可能在执行时没有合法范围目标。只有实际命中或实际效果应用后，才产生相应命中与效果事件。

## 当前限制

- 当前目标和执行语义只覆盖单机本地的四个技能样本，不承诺网络延迟、多人权威命中或跨地图目标同步。
- 当前行为集合不覆盖方向技能、锥形技能、引导技能或更复杂的命中规则。
