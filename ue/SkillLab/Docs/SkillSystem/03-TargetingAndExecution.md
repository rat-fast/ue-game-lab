# 目标与执行

## 职责

定义当前可用的目标校验、目标快照和执行方式，不扩展尚未实现的空间技能语义。

## 当前承诺

当前支持 `Self` 与 `Unit` 目标类型。自身目标必须解析为施法者对象；单位目标必须是有效对象，并能解析到已初始化且非零的单位身份。请求中提供的目标单位身份与解析身份不一致时拒绝。

目标位置和方向会被保存在请求、结果和事件中；输入为空时，当前实现从解析目标补齐位置/朝向。当前执行方式是激活成功后直接解析目标并执行一次同步效果。

## 当前实现与验证

默认技能定义使用自身目标。代码对目标对象、目标类型、目标单位身份和目标上下文做校验；当前命令行验证覆盖自身目标成功路径，未覆盖多单位运行场景。

## 当前限制

当前没有已支持的地面/方向空间执行、敌友过滤、候选与正式命中重检、投射物、区域、引导、碰撞或命中去重。位置和方向字段目前只是快照，不代表已有空间执行能力。
