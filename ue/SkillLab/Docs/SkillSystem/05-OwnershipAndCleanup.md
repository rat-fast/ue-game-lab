# 所有权与清理

## 职责

记录当前请求、施法上下文、授予记录、冷却和属性恢复由哪些运行对象维护，以及 Reset 已实现的清理事实。

## 当前承诺

单位技能运行上下文维护当前请求、定义快照、当前授予身份、活动施法身份、冷却记录和能力/属性引用。授予记录保留技能身份、业务授予身份和底层授予句柄。效果结果保留来源、目标、请求和施法关联。

当前 Reset 会发布 `ResetStarted`，取消当前能力，恢复默认测试属性和技能能量，清空冷却；活动施法存在时记录 Reset 导致的中断，最后发布 `ResetCompleted` 并清理当前请求上下文。

## 当前实现与验证

命令行验证已观察到 Reset 开始/完成、冷却清空后再次施放和新的施法身份。当前没有独立投射物、区域或持续状态可供 Reset 管理。

## 当前限制

死亡、销毁、跨单位持续效果、对象独立存续、技能撤销后的活动实例处理和残留检测没有形成当前公共规则。不能从 Reset 的当前实现推导通用死亡清理顺序。
