# M01 输入与技能装配（详细设计草稿）

## 定位、依据与状态

上游：[范围](../../SkillSystemRequirements.md)、[第二层总览](../02-CapabilityModel.md)、[模块地图](../README.md)。

**已确认需求**：按键、逻辑动作、槽位和技能分开；需要运行中点击槽位换技能的简单 UI；需要目标预览、确认与取消；玩家、AI、测试共用施法规则；表现与逻辑解耦。

**AI 建议默认方案**：本文其余具体交互和换装规则用于评审与后续试玩，尚未由用户逐项确认，也未实现验证。可调项可后续调整；涉及多个模块的规则，实施前应在相应模块中形成一致约定。

现有输入文档记录右键单击移动、右键拖动旋转镜头、滚轮缩放。新交互必须处理这些输入的冲突；接入代码时仍需核对真实实现。本文不宣称技能 UI 或 GAS 已存在。

## 一、职责与边界

M01 负责玩家输入解释、槽位映射、装配操作、瞄准交互状态和请求形成。运行中选择技能不应要求手改角色配置。

相关模块：

| 模块 | M01 使用的约定 | M01 不接管的职责 |
|---|---|---|
| M02 单位与能力基础 | 可用技能列表、能力身份、授予/移除结果、死亡与重置通知 | ASC 生命周期、能力授予实现 |
| M03 定义与施法生命周期 | 技能输入需求、请求提交/结果、冷却和可用性查询、缓冲失效入口 | 激活、扣费、冷却、施法中断和缓冲执行 |
| M04 目标与命中 | 预览数据、目标解析/校验结果 | 空间查询、命中和效果合法性 |
| M07 表现与反馈 | 槽位、预览和请求结果事件 | 资源接线、动画、特效与音频 |
| M08 测试调用 | 提供受控换装接口；测试可直接请求技能 | AI 决策和批量调度 |

本表为下游需要实现的语义接口，不是现有 API。M02～M04 详细稿尚未建立，对接前补齐对应契约。

## 二、核心数据边界

| 概念 | 含义 |
|---|---|
| 技能定义标识 | Fireball 等可复用内容身份；不等于一次施法 |
| 可用技能集合 | 本单位允许选用的技能，由 M02 提供；区别于全项目技能目录 |
| 能力授予记录 | 该单位实际获得的可调用能力，由 M02/GAS 管理 |
| 装配 | 单位、槽位标识与技能身份的对应关系 |
| 输入动作 | “激活槽位 1”等逻辑动作；Q 是该动作的一种按键绑定 |
| 交互状态 | 空闲、查看换装列表、瞄准某技能；与技能运行阶段分开 |
| 请求身份 | 提交时确定的单位和技能身份；不得稍后重新读槽位调用其他技能 |

测试地图可把测试技能集合授予单位，再从中装配；实际授予策略由 M02 决定。首版建议同一技能不重复装入多个槽位；未来允许重复时，必须明确冷却共享规则。

## 三、最简单的可玩交互（建议默认）

建议先有四个槽位，绑定 Q/W/E/R，数量与映射可配置，不作为系统硬上限。首版无需制作玩家自定义键位设置菜单。

### 准备与装配

1. 点击快捷栏槽位，打开该槽位的可用技能列表；点击槽位不同时施法。
2. 选择技能，提交装配变更；可选择清空槽位。
3. M02 确认可用后更新装配，UI 根据实际结果刷新。失败时保留原装配并显示原因。
4. Esc 关闭列表。首版提供名称、图标或占位符、简短说明；搜索、分类和长期保存可后补。
5. 测试模式允许运行中换装，不要求暂停世界。

### 使用与瞄准

1. 按槽位键，立即解析当时装配的技能。空槽给出提示。
2. 自身/无需选点的技能可直接形成请求；需要单位、地面或方向的技能进入瞄准。
3. 鼠标移动更新预览；左键确认，Esc 取消。目标无效时保留预览并提示原因。
4. 确认有效候选后提交请求并退出预览；最终激活仍由 M03 重检，不把预览有效等同激活成功。
5. 瞄准期间按另一个非空槽位键，取消旧预览并处理新技能；按当前槽位键不重复生成请求。
6. 建议普通技能使用按下事件，按住不连发。需要松开、蓄力、持续按住的技能由 M03 声明输入需求，后续输入按已开始的会话身份转发，不重新解析当前槽位。

这一版不要求实现自动连发、蓄力等全部交互变体；生命周期模型应能接入，不能把所有技能永久绑定成按下即瞬发。

### 与现有输入的优先关系

- 点击 UI 消耗该次指针事件，不再触发世界确认、移动或镜头操作。
- 换装列表打开期间，技能快捷键不触发战斗请求；Esc 只关闭最上层交互。
- 瞄准时右键单击建议取消瞄准，并消耗这次点击，不同时移动；右键拖动保留镜头旋转，不同时取消。
- 单击与拖动在已有手势识别后分流。预览取消不自动中断已经开始的技能。
- 应用失去焦点或切换被控单位时，清理未提交预览和按住状态，避免回来后误触发。

## 四、装配改变时发生什么（建议默认）

| 场景 | 默认行为 |
|---|---|
| 正在预览的槽位换装/清空 | 取消旧预览，成功更新后显示新技能；不提交旧预览 |
| 旧技能已开始，或已有投射物/区域 | 槽位变更不主动终止它们，继续遵守原技能生命周期 |
| 有该槽位产生的待执行缓冲请求 | 通知 M03 使尚未开始的旧请求失效；不把它改成新技能 |
| Fireball 正在冷却，换成治疗 | UI 显示治疗自身可用性；资源读取单位当前资源 |
| 冷却结束前再换回 Fireball | 保留其剩余冷却，不通过换装重置 |
| 可用集合撤销某技能 | 清空相应槽位和未提交预览；已开始实例按 M02/M03 撤销规则处理 |
| 死亡 | 禁止新请求，清理预览与待输入；M03 清缓冲，M02 协调运行中对象 |
| 场景重置 | 清理交互及待请求；建议保留本次试玩装配，M02 重置运行状态 |
| 退出本次试玩再开始 | 按场景默认装配初始化；暂不跨运行保存 |

冷却的具体键由 M03 决定，可能是技能或共享冷却组；固定要求是换装不能重置原有冷却。资源不是每个槽位自己的状态。UI 不得直接删除 Ability 或清空冷却来实现换装。

请求尚未开始时可校验装配版本或等价身份。**防止调用错误技能是固定约束，版本号并非强制实现方案。**

## 五、输入输出与状态反馈

以下是信息要求，不是最终字段名或序列化 schema。

| 操作 | 必要输入 | 结果与反馈 |
|---|---|---|
| 查询装配和列表 | 单位、槽位（如适用） | 已装配技能、可用集合、基础显示信息 |
| 修改装配 | 单位、槽位、技能或清空标识 | 成功后的真实装配，或拒绝原因；成功发装配变化事件 |
| 更新/确认预览 | 单位、已捕获技能身份、指针/方向信息 | M04 返回预览数据和合法性；确认时形成目标参数 |
| 提交技能请求 | 来源、单位、技能身份、目标参数、追踪标识及按需时间/装配身份 | M03 返回拒绝、开始，或启用缓冲时的暂存；后续结果可关联 |
| 读取槽位状态 | 单位、当前技能身份 | 冷却剩余、资源/状态阻塞、不可用原因及变化通知 |

UI 的可用性是提示，真正提交时仍须重检。列表、槽位和战斗逻辑共享能力系统提供的事实，不在 Widget 中重写资源和标签规则。

错误需可区分：未绑定动作、空槽、技能不可用、失效目标、装配已变化、激活拒绝、预览取消、开始后中断。预览取消无需伪装成失败施法实例。缺图标使用占位符，不影响施法。

## 六、配置、约束和实现自由

| 类型 | 内容 |
|---|---|
| 内容配置 | 默认装配、测试技能集合、图标名称、技能所需目标/输入模式 |
| 项目可调默认 | 槽位数量、按键映射、确认取消方式、是否允许测试中换装、重置保留装配策略 |
| 固定约束 | 输入不结算效果；提交不能绕过激活检查；取消预览不产生正式效果；换装不改技能定义、不使旧请求调用新技能 |
| 运行时状态 | 当前装配、预览会话、输入按住状态、查询到的冷却与阻塞；不回写技能定义 |
| 程序自主选择 | C++ 类/组件、Widget 组织、存储容器、版本机制、缓存刷新方式 |
| 相关模块拥有 | 扣费时点、冷却键、缓冲时长与重试条件、命中检查、死亡对象清理 |

重复技能、未知技能标识、失效按键映射应被装配/配置校验发现；无效配置给出原因而非静默装上错误技能。需要运行时配置覆盖不代表所有固定约束都必须可开关。

## 七、试玩检查点（尚未执行）

| 操作 | 应观察到的结果 |
|---|---|
| 连续按下与长按普通槽位键 | 每次按下尝试一次，长按不无意连发 |
| 空槽、资源不足、冷却中尝试 | 各自显示原因，不产生正式效果 |
| 预览后取消、换槽位、点击 UI | 不误施法；被消耗的输入不同时移动 |
| 换装后再按原键 | 调用新技能，旧投射物按原规则继续 |
| 冷却中换出再换回 | 剩余冷却仍在，不通过换装刷新 |
| 缓冲后换装、预览后死亡/重置 | 旧待请求失效，无复活后误触发或残留预览 |
| 非法装配请求 | 返回失败并保持原装配，UI 与实际一致 |
| 测试工具直接换装和施法 | 使用相同装配/激活规则，有可关联结果 |

这些是边试边改的检查点，不构成必须先完成的正式验收关卡。

## 八、实施边界与需要补齐的内容

本稿足够评审交互方案与拆解任务，还不足以单独完成 GAS 全链路。

- 可先设计装配数据、输入适配和 UI 展示骨架。
- 接通可玩链路前补齐 M02 的可用集合/授予与重置、M03 的请求结果/提交与冷却、M04 的预览和目标解析接口。
- 尚未纳入本稿实现：完整存档、背包成长、键位设置菜单、完整 AI 决策和多命令队列。
- 需要用户重点看的仅是：换装交互、瞄准确认取消、换装是否影响旧技能。槽位数量和具体按键可按建议先试玩调整。
