# M02 战斗单位与能力基础（详细设计草稿）

## 定位与状态

M02 定义哪些运行时对象可以拥有技能、属性、状态和能力系统，以及它们如何初始化、授予、死亡、重置和清理。

已确认：玩家、敌人、友方单位最终共享基础能力规则；需要死亡、重置、能力授予和清理；角色功能不持续堆入 Character。
AI 建议默认方案：本稿用于程序拆解和体验评审；具体 UE 类、组件和 GAS 初始化代码尚未确定或实现。

## 一、职责边界

M02 负责：

- 战斗单位身份、阵营和能力归属；
- AbilitySystemComponent（ASC）及属性/标签运行环境的初始化；
- 能力授予、移除和单位可用技能集合；
- 单位死亡、复活/重置和场景重置时的能力状态处理；
- 向其他模块提供单位有效性、阵营关系和能力身份。

M02 不负责：

- 具体技能如何消耗资源或命中；
- 输入、槽位和 UI 交互；
- 伤害、治疗和控制的具体数值结算；
- AI 如何选择技能；
- 表现资源播放。

## 二、单位模型

一个战斗单位至少包括：

- 稳定单位身份；
- 所属阵营和关系查询；
- 能力系统归属；
- 属性和资源集合；
- 当前状态标签；
- 当前拥有/授予的能力；
- 死亡、重置和清理状态。

单位不等于 Character。建议由 Actor/Character 加能力组件、属性组件和单位身份组件组成；最终程序结构由程序映射确定。

### 能力身份与技能内容身份

- 技能定义身份：Fireball 这样的可复用内容。
- 能力授予身份：某个单位当前获得的可激活能力记录。
- 施法实例身份：一次具体运行。
- 槽位身份：输入装配的位置。

四者不可混用。移除槽位技能不等于销毁已经开始的施法实例。

## 三、初始化流程

单位生成
→ 建立单位身份与阵营
→ 创建/绑定 ASC
→ 初始化属性与基础标签
→ 授予默认能力和可用技能
→ 建立默认装配
→ 通知 UI、测试和调试入口

初始化必须可重复执行或明确拒绝重复初始化，不能因为重生/PIE 重置导致能力重复授予、属性叠加或残留标签。

初始化来源可以包括默认配置、角色模板、测试场景和运行时换装。来源需要可追踪，便于重置与调试。

## 四、能力授予与移除

能力授予需要记录：

- 目标单位；
- 技能定义身份；
- 授予来源；
- 是否允许装配；
- 是否临时；
- 授予版本或等价身份。

移除能力时：

- 未开始请求必须失效；
- 已开始实例按 M03 的取消/持续规则处理；
- 槽位装配由 M01 同步清理；
- UI 和日志收到实际结果；
- 不能留下不可见的冷却、监听器或标签。

默认建议：测试技能可以临时授予；场景重置移除临时授予并重新应用初始模板。

## 五、死亡、重置与清理

建议把三种情况分开：

| 情况 | 含义 | 默认处理 |
|---|---|---|
| 死亡 | 单位在当前战斗中失去正常行动资格 | 禁止新请求，通知 M03 清理/中断，清理预览和未执行缓冲 |
| 复活 | 同一单位重新获得行动资格 | 按项目规则恢复属性、状态和能力可用性 |
| 场景重置 | 为重复试玩恢复初始状态 | 取消运行实例、清除效果/状态/临时对象、重置属性和冷却、重新应用配置 |

死亡不应自动等同于删除 Actor。投射物和持续区域是否继续存在由其所属技能/对象规则决定，但必须收到死亡事件并有明确归属。

M02 负责发出生命周期通知并协调全局重置；各模块清理自己创建的对象。M02 不直接遍历并销毁所有对象的内部实现细节。

## 六、配置、固定约束与程序自由

可配置：单位模板、阵营、初始属性、默认能力、可用技能集合、是否可复活、死亡后的初始状态。

项目默认：单位死亡后不能发起新施法；重置后恢复初始属性、能力授予和冷却；临时测试授予不跨场景保留。

固定约束：

- 任何技能请求必须关联有效施法者；
- 死亡或已销毁单位不能静默发起请求；
- 能力授予和移除必须可追踪；
- 初始化和重置不能重复叠加属性、标签或能力；
- 单位清理必须能通知施法实例、效果、投射物和 UI。

程序可自行选择 ASC Owner/Avatar 的具体类、组件归属、初始化顺序实现方式、句柄存储方式和委托组织。

## 七、需要观察的结果

- 玩家、敌人、友方单位能用同一套单位能力接口；
- 重复重置不会出现重复能力、属性翻倍或残留标签；
- 死亡后按技能不会产生新实例；
- 临时授予技能可移除，槽位不会继续调用旧能力；
- 运行中的对象不会因 UI 槽位变化而错误绑定到新技能。

## 八、待确认

- 单位是否允许复活，以及复活保留哪些状态；
- 死亡时投射物、区域和持续效果的默认存续；
- 属性初始化采用模板、等级还是其他来源；
- 阵营关系是否需要动态变化；
- 场景重置是否保留本次装配。

## 九、与其他模块的交接

- 给 M01：可用技能集合、授予/移除结果、单位死亡和重置通知。
- 给 M03：有效施法者、能力身份、死亡和重置信号。
- 给 M04：单位身份、阵营和目标有效性。
- 给 M05：属性、资源、标签环境和状态生命周期。
- 给 M09：初始化、授予、移除、死亡和重置日志。
