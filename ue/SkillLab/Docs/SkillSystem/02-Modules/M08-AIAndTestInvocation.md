# M08 AI 与测试调用（详细设计草稿）

## 定位

M08 定义 AI 和测试工具如何使用技能系统，不建立一套绕过玩家规则的特殊施法路径。

## 职责

负责直接提交技能请求、提供目标参数、批量换装和批量试放、记录请求来源、重复运行和测试场景控制。

不负责完整敌人决策、技能效果、命中或施法生命周期。

## 统一入口

AI/测试可以跳过物理按键和 UI 预览，但从施法请求开始使用 M03 的统一激活、缓冲、目标、效果、表现和清理规则。

示例：

AI 决策“对最近敌人释放 Fireball”
→ 选择技能定义和目标
→ 构造施法请求
→ M03 激活检查
→ M04 目标重检
→ M06 执行
→ M05 结算

## 测试能力

需要支持：

- 运行中替换槽位；
- 指定技能、目标、位置和方向直接请求；
- 批量创建单位和授予能力；
- 重置场景和重复试放；
- 读取请求、命中、效果、失败和清理结果；
- 保存可复现的测试参数。

## 固定约束

- AI/测试不能跳过激活条件、阵营过滤和效果入口；
- 每次调用必须标记来源；
- 批量测试失败不能污染下一次运行；
- 测试工具可以提供额外调试信息，但不能改变正式规则；
- AI 生成内容必须经过配置校验。

## 需要用户重点确认

- AI 是否可以直接选择未装配技能；
- 测试模式是否允许无 UI 指定目标；
- 批量试放是否暂停世界；
- 测试重置是否保留当前装配。
