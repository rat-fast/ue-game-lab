# M04 目标与命中（详细设计草稿）

## 定位与状态

M04 负责把技能所需的目标形式转换为预览、确认、查询和实际命中结果。它区分玩家选中的目标、技能合法目标和执行时真正命中的目标。

已确认：需要自身、单位、地面位置、方向、敌友过滤，以及直接命中、范围、扇形、直线、投射物和持续区域的目标支持；需要目标预览和实际命中分离。
AI 建议默认方案：预览与命中之间的重检、锁定方式和空间边界需要结合首批技能确认。

## 一、职责边界

M04 负责：

- 目标需求描述；
- 单位、地面、方向和自身目标的解析；
- 目标预览数据与合法性提示；
- 阵营、距离、视线、碰撞和标签过滤；
- 释放时和执行过程中的候选查询；
- 实际命中事件和命中去重；
- 目标失效、离开范围、免疫和命中重检结果。

M04 不负责：

- 输入按键和技能槽位；
- 资源和冷却；
- 伤害治疗和状态数值；
- 投射物自身移动；
- UI 资源播放。

## 二、三种目标结果

| 结果 | 发生时间 | 含义 |
|---|---|---|
| 目标意向/输入 | 预览前后 | 玩家、AI 或测试想指向什么；不是最终命中 |
| 目标解析结果 | 提交请求时 | 单位、位置或方向等上下文；供 M03 形成请求 |
| 实际命中结果 | 释放、碰撞、范围查询或周期检查时 | 当前规则下真正被命中的目标，可能为空或与解析结果不同 |

不要求为目标意向单独创建运行对象；它是入口概念。目标解析结果要能被请求携带，实际命中由执行时重新查询或验证。

## 三、目标类型

首版至少支持：

- 自身；
- 单个单位；
- 单位列表或范围候选；
- 地面位置；
- 方向；
- 以施法者、目标或地面位置为中心的范围；
- 直线、扇形和持续区域查询。

目标需求应声明是否需要视线、是否允许自身、友方、敌方、中立、是否允许死亡单位、是否允许不可选中单位，以及超出距离时的处理。

## 四、预览与确认流程

按槽位键
→ M01 读取技能目标需求
→ 建立预览会话
→ 鼠标/方向变化
→ M04 返回范围、候选和合法性
→ 玩家确认或取消
→ 形成目标解析结果
→ M03 再次检查并提交请求

预览只是帮助玩家选择，不锁定最终结果。默认确认时捕获单位/位置/方向快照；执行时根据技能规则重检。

AI 和测试可以直接提供单位、位置或方向，跳过 UI 预览，但必须使用同一套合法性检查。

## 五、查询与命中规则

### 释放时查询

适用于瞬发范围、扇形、直线和直接目标。查询时检查：

- 距离和范围；
- 阵营关系；
- 视线/碰撞（技能声明需要时）；
- 目标状态和免疫；
- 每次施法或每段的命中去重。

### 投射物命中

M06 提供碰撞位置和候选对象，M04 负责阵营、标签、距离容差、命中过滤和去重，再将合法命中交给 M05。

### 持续区域/周期查询

区域由 M06 持有生命周期；M04 在创建、进入、离开或周期检查时提供候选和合法性结果。技能定义要声明同一目标能否重复命中。

实际命中不应直接信任预览候选。目标死亡、移动、获得免疫或离开范围后，命中结果可以改变。

## 六、配置、固定约束与程序自由

可配置：目标类型、范围形状、半径/长度/角度、最大距离、阵营过滤、视线要求、命中频率、同一目标去重、锁定策略、目标失效处理。

固定约束：

- 预览合法不等于最终命中；
- 实际命中必须经过统一过滤；
- 目标解析、候选查询和命中事件可追踪；
- 不允许某个技能绕过阵营和免疫规则直接写目标属性；
- 命中事件应能关联施法实例、来源技能和目标。

程序可选择 UE 碰撞查询、Gameplay Ability Target Actor、组件或其他空间查询实现。

## 七、关键默认建议

- 单位目标默认在确认时捕获，但释放时重检有效性；
- 地面目标默认捕获确认位置，超出范围时按技能声明截断或拒绝；
- 方向目标默认在确认时捕获方向，释放后不随鼠标继续变化；
- 范围技能默认一次命中去重，多段技能按段重新判断；
- 持续区域默认可声明进入命中、周期命中或离开命中；
- 目标死亡、不可选中或免疫时不产生对应效果，不回溯修改已经发生的效果。

## 八、观察点与待确认

需要观察：

- 鼠标目标、地面范围和方向预览是否准确；
- 预览取消不会命中；
- 目标在确认后移动/死亡/获得免疫时结果是否符合技能规则；
- 投射物穿过多个单位时去重和过滤是否正确；
- 持续区域的重复命中是否可预测；
- AI/测试直接请求与玩家请求结果是否一致。

用户重点确认：

- 单位目标是锁定确认时对象还是释放时重新选择；
- 地面目标超出距离是截断还是拒绝；
- 投射物是否允许穿透和多目标；
- 持续区域默认周期和重复命中方式；
- 预览范围与最终碰撞边界是否允许不同。

## 九、模块交接

- M01 提供预览启动、鼠标/方向输入和确认/取消；
- M02 提供单位身份、阵营和状态；
- M03 提供技能目标需求、施法上下文和阶段；
- M05 接收合法命中并应用效果；
- M06 提供投射物、区域、位移过程中的候选；
- M07 显示预览、命中和失效反馈；
- M09 记录解析、查询、过滤和命中结果。
