# 技能系统领域模型

## 职责

定义当前共享业务基线使用的概念、身份和对象关系。只描述当前系统已经承诺并由现有运行链承载的最小模型。

## 当前承诺

- **单位**拥有单位身份、属性环境和已授予技能资格，可以作为施法者或目标。
- **技能定义**是带身份、版本、来源、目标类型、资源/冷却和效果描述的可复用内容记录。
- **授予资格**表示单位当前拥有某个技能；它与技能定义和一次请求分开。
- **请求**表示一次提交尝试；**施法**表示激活成功后形成的一次运行实例。
- **目标快照**保存目标对象/单位身份以及位置、方向信息；它与实际效果结果分开。
- **效果应用**记录一次效果尝试的来源、目标、技能、请求、施法、名义量和实际量。
- **事件**记录初始化、授予、校验、开始、目标解析、效果、完成、拒绝和 Reset 等运行事实。

当前稳定运行链为：单位初始化 → 授予默认技能 → 提交请求 → 激活成功形成施法 → 解析目标 → 应用同步瞬时效果 → 发布结果事件。

## 当前实现与验证

当前实现有两个可用的自身目标瞬时技能样本；请求、施法和效果身份均能出现在结构化结果/事件中。命令行验证已观察到授予、成功施法、冷却拒绝、效果结果和 Reset 事件。

## 当前限制

当前模型没有已承诺的槽位、预览会话、复杂阵营、空间执行对象、持续状态或网络身份语义。相关概念不应从长期策划材料直接升级为当前基线。
