# 输入与请求入口

## 职责

记录当前已支持的请求来源和请求输入边界，不定义尚未实现的完整意图、预览或 UI 系统。

## 当前承诺

请求可以带来源、施法者对象与单位身份、技能身份、目标类型、目标对象/单位身份、目标位置和方向。来源语义包含 `Test`，请求结构也保留 `Player` 与 `AI` 来源值。当前公开可验证的调用路径是测试入口提交统一请求。

请求提交时使用技能身份和目标信息形成当前请求上下文；后续结果和事件继续携带这些身份与位置/方向快照。

## 当前实现与验证

当前实现要求施法者对象必须是所属单位对象，施法者单位身份必须匹配当前单位。测试命令只填写来源、施法者、技能身份和自身目标后进入统一请求路径；命令行验证已证明该路径可产生成功、拒绝和 Reset 事件。

## 当前限制

当前没有已验证的玩家按键适配、AI 实际调用、槽位装配、目标预览、确认/取消会话、失焦处理或输入缓冲。`LoadoutVersion`、位置和方向字段存在于请求结构，但尚未形成独立装配或预览业务。

## 关系

请求门控和施法阶段见 `02-RequestLifecycle.md`；目标字段的解析见 `03-TargetingAndExecution.md`。输入层不负责资源、冷却、命中或效果结算。
