# SkillLab 程序工作流文档入口

本目录只保存程序架构、批次交接和 Review 状态，不保存完整代码地图、策划正文或原始编译日志。

每个领域使用独立任务目录，并按长期程序框架与批次产物组织。表现程序工作流从 `AnimationWorkflow/README.md` 进入；它只保存当前批次的架构、实现交接、Review 和验证证据，不承载表现策划正文或共享业务基线。

跨业务模块的公共 Lua 运行时去重任务从 [LuaRuntimeModuleRefactor/README.md](LuaRuntimeModuleRefactor/README.md) 进入，包含本次交付状态及架构、实现、Review 和验证证据入口。
